## 3. 事件到画面

| 事件 | 画面 | 时长 |
|---|---|---|
| `snapshot` | 群岛与已有航线、港灯一次铺开，镜头从高空推入 | 2.5s |
| `node_join`（agent） | 一道光从高空斜落，触到海面时一圈涟漪，港灯点亮 | 落下 2.4s（给镜头推近留时间），涟漪 1.4s |
| `node_join`（config） | 新港：见“开垦” | |
| `node_leave` | 港灯熄灭成灰点，它的航线转灰痕 | 1.2s |
| `probe` | from 港起飞若干航班，空中弧线飞向 to 港；画成一道 1 像素的细光迹加一个头部光点 | 0.9–1.6s，弧高为距离的 0.22 |
| `batch` | 同一批次的判断在 150ms 内一齐闪，读出来是“一批” | |
| `judge` act | 两港之间一次暖色短弧，目标港闪亮 | 闪 0.45s |
| `judge` ignore | 灰色细闪，几乎不可见 | 0.3s |
| `judge` unsure | 朱色闪，留一个朱点在 a 港上方 | 0.6s |
| `unsure_route` disclose_request | 朱色信号弹从 a 飞向 ask_to | 1.2s |
| `disclose_request` granted / denied | 回程航班暖色 / 灰色；granted 时目标港多一圈层级环 | 1.0s |
| `disclose` | 港灯亮度台阶式升一级，层级环 +1 | 0.6s |
| `edge` new | 海面上出现一条很淡的候选航线 | 0.6s 淡入 |
| `edge` up / down | 航线变宽变实 / 变窄；只有 up 过或 conf ≥ 0.8 的航线才有船光，速度与密度随 conf | 0.6s |
| `edge` gone | 航线退成灰痕，留在海面 90 秒后才淡尽 | |
| `config` candidate / judged / growing | 成员港之间的航线短暂同时加亮，成员港外圈出现细环 | 1.0s |
| `config_grow` | 新成员港亮一下，一条航线接入；tighter_p 低时用灰 | 0.8s |
| `config` plan | **开垦**：成员港各派一串船光沿海面汇向新址，抵达时新港点亮，上方画出该构型拓扑的蓝图 | 船队 3.2s，点亮 0.7s，蓝图描线 1.4s |
| `plan` | 字幕浮出方案标题与置信度；蓝图停在新港上方，之后降到 25% 亮度常驻 | |
| `node_join`（config，shape=meta） | 全片唯一的破例：一道光从新港向外扫过整个网络，港灯与航线依次亮一下 | 6s |
| `invalidate` | 受影响港灯同时闪一下暗（读作“重算”） | 0.4s |
| `stats` | 左下角一行安静的数字 | |
| `spotlight` | 不直接画，只给导演镜头一个候选 | |
| `config` dissolved | 蓝图碎成灰点落入海面 | 1.5s |

没有事件时只发生两种慢变化：灰痕褪色、刚变化过的东西回到常态亮度。

量的规矩：港灯大小与亮度随披露层级和机会数（未褪去的航线数加所在构型数）增长；航线宽 0.3–1.7 单位，随 conf² 增长，屏幕上至少 1 像素；长航线按长度摊薄亮度（参照长度 140 单位，最低 30%），避免跨岛的长线压过岛内的网。陆地由 agent 自己长出来：语义坐标下每个 agent 周围撒一小片地面点，人聚在哪里，哪里就是岛；没有语义坐标时按城市排岛。每个地面点是一块柔光地皮加一粒 1 像素颗粒，近看连成陆地，远看是颗粒，这样近景里港灯之间是地面，不会读成星图。海面只有静止的涌浪纹理，不随时间动。

## 4. 运动

- 所有出现用 `cubic-bezier(0.16, 1, 0.3, 1)`（快进慢停），消失用 `cubic-bezier(0.7, 0, 0.84, 0)`。
- 闪光一律指数衰减 `exp(-t/τ)`，τ 取上表时长的三分之一。
- 航班沿二次贝塞尔弧飞，速度两头慢中间快（smoothstep）。
- 船光沿航线匀速；速度 = 0.04 + 0.12×conf（航线长度单位/秒），密度 = 2 + 10×conf 个/条。

## 5. 镜头

**裁定：一镜到底，不切镜头。** Nature 否掉过所有靠切换和转场的草图（`world/项目锚点.md` 原话第 20、23 条），宣传片的节奏只靠一个连续镜头里的变速、推拉、环绕和焦点转移来做。之后的调研若建议硬切，以本条为准，要改先问 Nature。

导演模式（默认）：

| 镜头 | 做法 | 用在 |
|---|---|---|
| 巡航 | 距中心 1.75 倍群岛半径，俯角 52°，方位角 1.5°/s 缓慢转 | 空闲、每两个近景之后回一次全景 |
| 推近 | 目标点上方 160–240 单位，3s 内到位 | spotlight、node_join |
| 环绕 | 绕目标半径 180，6°/s | config judged、plan |
| 跟随 | 目标是船队质心，随它移动 | 开垦全程 |
| 拉远 | 1.5 倍当前距离，留出周边网络 | plan 字幕结束后 |

- 机位与注视点用临界阻尼弹簧追目标（导演 ω=1.4，用户回归 ω=1.0），任何时候都不瞬移。
- 每个镜头最少停 5 秒，最多 11 秒；优先级 plan > config judged > node_join > spotlight > 巡航。
- 每两个近景之后插一次巡航，让观众重新看见全局。
- 用户拖动、滚轮、触摸即转为自由模式；6 秒无操作，镜头沿弹簧回到导演模式，不跳。
- 接入特写用更快的弹簧（ω=2.1），让镜头在光落到海面前赶到。
- 竖屏时水平视野窄，所有镜头距离乘 min(2.2, 1.78/宽高比) 的 0.7 次方。

**与调研 `context/03-产品与宣传片调研.md` 的取舍。** 采用：先露轮廓后填亮（蓝图先描线再常驻）、一次破例（构型再组合时的全网扫光）、失败也要画出来（灰痕）、真实或标明模拟（左下角“模拟数据”）、结果可点开看依据（信息层）、帧率监测降档。不采用：瞬时反馈用硬切，它与本节一镜到底的裁定冲突；数据用等宽字体，它在禁用清单里；单一强调色改为两种渗透色各管一件事，朱信号只表示拿不准，蓝图白只表示定案。

## 6. 文字

- 同一时刻最多一行字幕，屏幕下方 14% 处居中。淡入 0.5s，停 3.2s，淡出 0.9s。
- 只在四个时刻出字：构型定案（谁和谁、什么形式、置信度）、方案落定（标题、置信度）、特写的新接入（谁的什么 agent、在哪）、补信息被批准的那一次特写。
- 写法示例：「林岚、周野、阿木组成三人团队，置信度 0.82」。不用中点串、不用全大写小标签、不加箭头。
- 左下角常驻一行：「512 个 agent，每分钟 4,210 次判断，31 个构型」；模拟源与回放前面加「模拟数据。」。不做其他常驻读数。
- 中文与拉丁字母、数字之间自动加空格。手机上信息层打开时隐藏字幕。

                                         │                       │
                                         │ 披露                   │
                                         │            ▁▁▁ 3 信任后 │
                                         │        ▁▁▁▏    2 有苗头 │  ← 台阶：已到的层实线，
                                         │    ▁▁▁▏        1 公开   │     未到的层虚线
                                         │ ▁▁▁▏           0 一句话 │

2026-10-04 补充（真实接入回放定稿时）：

- `?me` 时侧栏常驻，且**画面让出右侧 380px**，侧栏不压在画面上；点开别人的港仍是覆盖式。
- 「已看到的层」改写成「这一对已释放的层（双方合计）」：`tier_seen` 是两边加起来已经释放给对方的层的并集，不分方向。
- 题面里的人名是后端短称，与节点标签对不上时，用「两个名字里有一个是这一对里某个节点的标签、另一个就是剩下那个节点」改成节点标签；猜不出来就保持原样。
- 节点标签与后端短称同一条规则：按「，,。；;」切、取第一段、最多 12 字（拉丁文 24 字符）；字幕里整名放进去，不再二次截断。

## 7a. ?me 与真实接入回放（`?replay=nature`）

一个真 agent 进网络，网络替它在人群里找人，对方来要信息，它多给一层，有的机会成形、有的被放下。这条故事线靠下面几条画面规则讲出来；事件不变，只是把一个毫秒里到达的一整批判断，按候选顺序拆开放。

| 事件 | 画面 | 时间（相对接入落地） |
|---|---|---|
| `probe`（from 是 ?me） | **召回**：镜头从全网远景推到 ?me 再拉开（`pull`，距离 1.25 倍群岛半径，俯角 58°）；32 个候选依次被一根探针点亮，每人身后留一道淡航线，候选港灯变大变亮，保持到判完 | 光落地后 0.2s 起，每个候选间隔 75ms，约 2.4s 排完 |
| `judge`（开放题，exit=ignore，且没在向对方要信息） | **暗下去**：候选港灯熄成灰点（比周围小 30%），淡航线退成灰痕，扩出一圈极淡的灰环；字幕说「N 个判『不成立』，暗了下去；M 个拿不准，去向对方要信息」，数字是前端按事件数出来的 | 召回之后 2.6s 起，同样按候选顺序排开 |
| `disclose_request` / `unsure_route` / `disclose`（牵涉 ?me） | 信使往返：只画牵涉 ?me 的信使，别人之间的往来只闪港灯；朱色信号弹去、暖色或灰色回程；多给一层时目标港多一圈层级环 | 同一候选的事件保序，整体比到达晚 5s 起 |
| `edge` new（牵涉 ?me） | **收成航线**：沿用召回时画好的那条淡航线，变成最粗最亮的一条，带船光，两端各出一圈环，并闪两次冷白；镜头拉到两端之间 | 与到达同步，镜头 6.5–8.5s |
| `edge` gone，但从没出现过 new | **看过、放下**：这条线亮一下（冷白）再退成灰痕，两端港灯一闪后暗下去；字幕「N 个看过的候选放下了（判『不成立』的把握 a–b）」，读数是这个候选两个方向的开放题里较弱的那个 | 亮 1.0s，灰痕留 90s |
| 第二次 `probe`（from 是 ?me） | 再来一扇：字幕「网络又为 X 召回 N 个候选」 | 同上 |

- ?me 的 agent 自己始终带一圈白环，画面里一眼认得出「我」在哪。
- 同一处 1.6 秒内不叠第二圈光圈。
- 字幕分两级：叙述（召回、放下、第一个机会、再判）优先级 1，补信息的单条字幕优先级 0；一条在播时只留一条待播，优先级不低于它的新字幕才能顶掉它。
- 全程 60–90 秒（4 倍速下 nature 回放 72 秒加上约 7 秒的拆分延迟）。

**航线与开垦。** 航线（海面上的线、船光、灰痕）在两份回放里都看得到。开垦新港（船队、新港点亮、蓝图）只在有构型的回放里出现，即 `?replay=full`；nature 回放里背景 agent 彼此不判断，没有构型，所以没有开垦。

## 8. 性能预算

| 项 | 预算 |
|---|---|
| 设备像素比 | 上限 1.5（`n>3000` 时 1.25） |
| 泛光 | 半分辨率 |
| 主要绘制调用 | 地面、港灯、航线、航班、船光、蓝图、涟漪，共 ≤ 10 |
| 每帧 JS | 不遍历节点；只处理本帧事件，写缓冲区的局部区间 |
| 航班池 | 5000 架（一万节点时 12000 架），每架 12 个尾迹顶点，环形复用 |
| 航线 | 一万节点时上限 40,000 条，实例化带状网格 |
| 降档 | 连续 2 秒中位帧时间 > 22ms，像素比降 0.25，最低 0.75 |
| 目标 | 500 节点 60fps；一万节点 ≥ 30fps（实测见 `PERF.md`） |

## 9. 首页模式（towow.ai、net.towow.ai、`?home=1`）

全屏 3D 网络照常运行，上面只压一层字，代码在 `src/home.ts`，样式在 `index.html` 的 `#home`、`#home-nav`。

| 项 | 规定 |
|---|---|
| 内容 | 一句标题、一段说明、一行可点击复制的接入命令、Codex 命令、当前人数、回放说明；顶栏是字标、实时与回放、说明、源码、语言 |
| 位置 | 左下，背后一圈径向暗晕托住文字；旁白移到上方 15vh，避开文字块 |
| 字 | 标题衬线 40px（手机 26px）；两行命令用系统等宽字（苹方会把 `--` 画成接近长划的字形，照抄会抄错），钠灯色加下划线，关掉连字；Codex 命令可整段选中 |
| 事件源 | 显式 `?src=live` 或 `?replay=` 优先；否则 `/healthz` 有真人或 5 分钟内有判断时连 `/live`（公开画面，不带 token、不拉 `/api`），安静或连不上时放 10-04 的 500 人回放，并写明是回放 |
| 语言 | `?lang=zh|en`，缺省看浏览器语言；英文版翻译首页字层、左下状态行与旁白的句子模板；旁白里引用的居民资料（称呼、展示语）保持中文原文；信息面板不翻译 |
| 不做 | 卡片、玻璃拟态、箭头符号、大写字距标签、装饰性等宽字、假编号 |
