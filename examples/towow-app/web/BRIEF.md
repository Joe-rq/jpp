# 通爻网前端：简报、艺术指导与方向取舍

2026-10-04。按 `~/.agents/DESIGN-METHOD.md` 的顺序写：先简报和艺术指导，再发散 12 个方向、对照痕迹表与禁用清单砍到一个。选定方向的机械规范在 [DESIGN.md](DESIGN.md)，后续改动先读那份。

## 一、简报

**要让人看见什么。** 几百到一万个 personal agent 接入一张陌生发现网络，每个只交出很少的上下文。网络里的判断器（JEV）每分钟判几千次两两关系；拿不准时向 agent 要更多信息；关系聚成链、环、团队、一对多、多对多，构型还能再组合；最后写出带置信度的合作方案。前端要让人看见这个持续计算本身，以及一个新 agent 接入后几秒内找到机会。

**给谁看。** 做 agent 的年轻开发者、评审与投资人。他们看几十秒宣传片式的画面就要明白三件事：判断很多、很快、很便宜；拿不准会变成补信息，而不是被丢掉；多方合作是从两两判断里长出来的。

**约束。** 画面上的每一个动作都对应一条事件（`design/events.md`），没有事件时只有缓慢的定律变化（光暗下去、旧航线褪色），不为热闹加假动作。Agent 不用人像。关系必须是有交通的通路，Nature 两次否掉过只画光线表示依赖。量照实：披露层级、机会数、构型人数决定大小和亮度。500 节点 60fps，一万节点不低于 30fps。

**成功标准。** 把所有文字藏起来截一张图，仍分得清哪里在判断、哪里拿不准、哪里谈成了；第一次看的人能指出哪一座港是刚形成的合作。

## 三、艺术指导

**一句实物隐喻：从高空看一片夜里的群岛，空中的航班在试探，海上的航线在落定，谈成的几座港各派一支船队，在空海上点亮一座新港。**

空中和海上对应两种不同的东西。判断是轻的、快的、便宜的、大量的，所以走空中，像夜航的航班，飞过就散。关系一旦被确认，就落到海面上成为航线，有船在上面来回，确认越多航线越宽。构型结晶时，成员各自派出船队，在它们之间的海面汇合，点亮一座新港；新港本身也是一个节点，可以再和别的港组成更大的构型，这就是组合封闭。

**像什么。** 宇航员从轨道上拍的地球夜景；夜里航空管制图上真实的航班密度；港口延时摄影里船的光迹；Powers of Ten 那种不切镜头的连续推拉。

**绝对不能像什么。** 赛博紫蓝渐变的“AI 大脑”与神经元放电；星座连线图；黑底青色雷达和抬头显示；满屏图表的监控大屏；玻璃卡片侧栏；米白底杂志排版；粒子乱飘只为好看的屏保。

**签名元素：开垦。** 一个构型定案时，成员港各派一串船光沿海面汇向新址，抵达瞬间新港点亮，上方投出一张冷白色蓝图，蓝图画的就是这个构型的拓扑（链是一条折线、环是一个圈、一对多是放射）。整片画面只在这一刻用冷白色，其余都是钠灯暖色和夜海。

## 五、狠砍与理由

| # | 结论 | 理由 |
|---|---|---|
| 2 星图 | 淘汰 | 星座连线就是光线表示关系，违背“关系是真实的通路”；星图也是数据可视化最常见的默认值。 |
| 3 神经放电 | 淘汰 | 正中“AI 大脑”和紫蓝科技风；也把网络说成一个中心化的头脑，而这张网恰恰没有任何一方持有全局。 |
| 4 菌丝林地 | 淘汰 | 节奏太慢，几千次每分钟的判断在菌丝里只能是模糊的流；一万节点下管状几何吃不消。 |
| 5 椋鸟群 | 淘汰 | 节点一直在飞，点不中、找不回；关系没有通路，只有队形。 |
| 6 深海发光 | 淘汰 | 青蓝发光生物是宣传片高频默认；关系依旧靠光。 |
| 7 塔台雷达 | 淘汰 | 雷达扫描线和抬头显示就是禁用清单里的仪表盘美学。 |
| 8 织机 | 淘汰 | 二维平面隐喻，3D 只能做成一块布；多方构型在布纹里读不出形状。 |
| 9 过饱和溶液 | 并入 1 | “结晶”的瞬间很好，作为新港点亮那一下的运动质感保留；溶液本身没有地点感，节点无处安放。 |
| 10 城市延时 | 并入 1 | 车流光轨讲清了“走得越多路越宽”，作为海上航线的交通表现保留；单座城装不下几百个互不相识的主体。 |
| 11 墨滴入水 | 淘汰 | 渗透之后边界消失，分不清谁和谁；点击和读数都无从落脚。 |
| 12 行星系 | 淘汰 | 节点沿轨道运动，位置不稳；轨道共振对观众需要解释。 |
| 1 夜航群岛 | **选定** | 见下。 |

**为什么是夜航群岛。** 它从三条更上位的规矩推出来，飞机和舰队只是落点。第一，关系必须是有交通的通路：海上航线天然是一条有船在走的路，宽窄照确认次数。第二，判断和确认的分量不同：空中航班轻、快、多、飞过即散，对应便宜的大量判断；海上航线重、慢、留得住，对应被确认的关系；拿不准时的补信息请求是一发朱色信号，从空中飞回去要东西。第三，组合封闭要看得见：新港由成员港的船队建成，它本身又是一座港，能再派船参与更大的构型，这也接上了“一沙一世界”，推近一座新港就能看见组成它的那几条航线。夜景还有一个实际好处：黑底上的暖色点光，一万个点也不乱，帧率便宜。

**两遍法自查。** 第一遍方案出来后对照痕迹表：暗底加单一强调色是常见默认，所以强调色拆成三种各有职责的颜色（钠灯暖、朱色拿不准、冷白蓝图），而且冷白只在开垦时出现；“地球夜景”容易做成蓝色星球加光晕，所以不画球体和大气辉光，只画群岛的地面点阵与海面；文字一律走电影字幕的单行，不做标题区、不加小标签。
