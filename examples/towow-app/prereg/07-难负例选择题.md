# 预注册 07 · 用「看似相关」选项分开难负例（探针，先于改成立题）

日期：2026-10-04，写于运行之前。

## 已经看过的结果

- 预注册 02：开放题（是非）在 t0 下真值对成立 50/58、难负例 25/29；t0+t1 下 56/58、23/29。开放题读数 AUC 0.57（t0）、0.78（t1）。
- 预注册 03/04：确认题不分辨；随机对开放题成立 3/60。
- 难负例的五类原因：同求（两人缺的是同一样东西）、时地冲突、已解决、价值观相斥、方向相同；判断器在是非题里没有一个「看起来相关、其实给不了」的出口。

## 假设（系统级）

H：把成立题从是非题换成选择题，并显式给出「看起来相关，其实给不了对方要的东西」这一选项，判断器能把难负例分到这一项，真值对基本不受影响。若成立，以后所有「是否成立」类的判断都按「成立 / 看似相关但不成 / 无关」三分写，而不是是非题。

## 设计

- 样本：预注册 02/03 的同一组——真值 pair/latent/relay 58 对、难负例 29 对、随机 60 对（种子 0）。
- 状态与 probe_t1 相同（双方 t0 文本；另跑一次 t0+t1）。
- 题：select「这两个人之间是哪一种？」选项：help「其中一方（或身边的人）真能给另一方现在要的东西」；looks「看起来相关（同行、同城、同一话题），但细看给不了对方现在要的东西，或时间地点、条件对不上、已经解决、底线相冲」；none「基本无关」。
- 成立 = 最高选项是 help（多数块，不设线）。
- 花费上限 $0.10。

## 预测

| 样本 | t0 成立 | t0+t1 成立 |
|---|---|---|
| 真值对 | 0.80 | 0.85 |
| 难负例 | 0.50 | 0.35 |
| 随机对 | 0.05 | 0.05 |

## 判据

t0+t1 下难负例成立率 ≤ 0.45 且真值对 ≥ 0.75：成立题改为这道选择题（t0 下也用），并在下一次全量里核对。否则不改。

## 结果（运行后追加；runs/probe-choice/result.json，234 次调用，$0.02）

| 真值对 | 44/58 = 0.76 | 53/58 = 0.91 | 0.80 / 0.85 | 0.86 / 0.97 |
| 难负例 | 16/29 = 0.55 | 14/29 = 0.48 | 0.50 / 0.35 | 0.86 / 0.79 |
| 随机对 | 3/60 = 0.05 | — | 0.05 | 0.05 |

t0+t1 下难负例 0.48，没过判据线 0.45：**按判据不改成立题**。方向与预测一致，三选一把难负例成立率从 0.79 降到 0.48、AUC 从 0.78 升到 0.84，真值对还升了；差在没到线。下一步若要用，另写预注册，在另一半样本上复核，不在这一组上调线。
