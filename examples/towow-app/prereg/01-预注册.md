# 预注册 01：通爻网 500 世界全量、N 梯度、消融

2026-10-04，主会话。本文件在任何真机全量花费、网络程序代码提交之前单独提交。真值文件的 sha256 在世界生成完成后以补记提交追加到第五节（补记提交同样早于全量运行）；补记只加哈希，不改预测。

## 一、系统假设（只为这些花钱）

- H1 路由：信号—catcher 同语义空间的 ANN 召回，真值对方命中率不随 N 稀释。
- H2 渐进披露：未决 → 问缺哪类 → 向持有方要 → 重判，对决定性事实在 t1/t2 的结构是必要的。
- H3 组合封闭：构型作为节点再进召回，对 meta 结构是必要的。
- H4 成本解耦：每次接入的判断调用数与 N 无关。
- H5 合批由运行时接管：作者写法不影响调用数。
- H6 置信度：决定性单题读数 `p_hold` 能区分真值对与难负例。

## 三、口径

- 命中：结构全体成员接入后 10 次接入内，系统以 `stage ≥ judged` 给出一个构型（或两两关系），其成员集合覆盖结构成员的 ≥ 80%（pair/latent/relay 要求两人都在），且形状一致或更大（团队多一人算命中）。
- 难负例：该对判为 act（成立）的比例。
- 质量：系统找出的非预埋构型随机抽 50 个，Opus 读双方世界与系统理由，评有价值/说得通/不成立；评审不读 plan、不读真值。
- 花费：只计 JEV 实际 input token × 4.2e-8；生成器走订阅，记次数与秒数。

## 四、运行顺序

1. 世界生成 → 真值冻结（sha256 补记进第五节并提交）。
2. 500 世界端侧编译（claude -p，缓存）。
3. 全量真机：随机顺序接入（种子写进账本头），再 30 次随机披露变化、20 次离开。
4. 消融：`--no-fill`、`--no-meta` 在含深层/ meta 结构的子集上真机各一次；`--no-cells`、`--no-batch` 用账本重放计数（零花费）；`--no-absent` 用模拟掉线。
5. N 梯度：离线合成背景到 2000、10000；同一组 20 个真值成员三档各真机接入一次。
6. 每次真机运行 < 5 美元，合计预计 3–4 美元。
