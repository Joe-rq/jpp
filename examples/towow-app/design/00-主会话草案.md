# 通爻网 · 主会话草案（交 Fable 裁定前）

2026-10-04。本文是主会话的初步方案，供两位 Fable 裁定与改写。依据：context/01、context/02、地基三份共识、Nature 2026-10-04 /goal 原话。

## 一、要交付什么

1. **实验版 J++（下称 J++x）**：用 Python 从头实现的一门小语言（语法贴近现行 .jpp），补上现行实现没有的「常驻、增量、进行中的计算参与其他计算」，并把运行时接管的八件事（批调度、深度与终止、未决去向、预算、缓存与增量、校准、判断力缺席、时延预算）做成运行时的职责。
2. **网络程序**：用 J++x 写的发现程序（网络侧）与端侧程序（agent 侧：从本地世界编译算子、决定披露）。
3. **宿主**：网络服务（事件流、MCP HTTP 端点、CLI），JEV 真机客户端，生成器（`claude -p`），编码器（bge-m3 本地）。
4. **500 个 agent 的实验世界**与冻结真值；1 万规模的成本/时延曲线。
5. **实时 3D 前端**。
6. **一条命令接入**：`claude mcp add --transport http towow http://localhost:8787/mcp`（远程 MCP，零安装），以及 `towow join` CLI。真实使用：本会话（Nature 的 Claude Code）接入并拿到机会。

## 二、「只有 J++ 才能做」的可证伪判据（先于设计）

下列四样必须落在语言/运行时，不得在宿主或应用代码里手写；每样配一个开关做消融，同一份程序开/关各跑一次：

| 能力 | 语言里的形式（草案） | 消融时预期看到 |
|---|---|---|
| 常驻增量计算 | `live` 定义：值依赖材料与其他 live 值；材料变了，运行时只让依赖它的判断失效重算 | 关掉：一次披露后全量重算，判断调用数 ×N |
| 未决默认去向 = 补信息 | `cut` 出 `unsure` 时，运行时并行问伴随题「缺哪类信息」（候选由生成器事先列好），向持有方发补信息请求（`ask` 效应，对象是 agent），补到即重判；对方拒绝则随返回值上交 | 关掉：深层（t1/t2）结构召回明显下降 |
| 跨主体合批 | 同一 state 上的所有题、来自不同方法/不同 agent 的题，由运行时合进一次调用；按时延预算排序 | 关掉：调用数 ×(每 state 平均题数) |
| 构型是一等值（组合封闭） | `Config` 与 `Agent` 实现同一个 `Node` 接口（有可判材料、有「能提供/还缺」），可再进召回与判断 | 关掉：meta 类结构召回为 0 |

另外两件写进运行时、也做开关：预算与时延预算（新接入者优先、每次接入调用数有上界）、判断力缺席（JEV 掉线时按画像降级到编码器相似度并标等级）。

## 三、网络程序的骨架（草案）

- **端侧编译算子**（生成，端侧做，一次编译多次判）：从本地世界产出 `needs`、`offers`、`latent`（未说出口的状态）、`relays`（一跳之内亲友能提供的）、`hypo_signals`（「我能接住的那种人会怎么说话」），每条带披露层。真实 agent 由它自己的模型做（MCP 工具把编译任务交给 agent）；500 个模拟 agent 用 `claude -p` 批量做并缓存。
- **召回（精确算法）**：bge-m3 编码；三路 ANN（我的 needs ↔ 对方 offers、我的 latent ↔ 对方 hypo_signals、我的 needs ↔ 对方 relays），每路 top-k，合并去重。成本与 N 无关（HNSW）。
- **两两判断（JEV）**：一对候选一个 state（JSON 具名槽：双方当前披露的材料），双向谓词全部挂上，运行时合批：能否接住、方向（谁给谁）、形式（K 选一）、价值（打分）、时机是否吻合。
- **未决 → 补信息**（见二）。
- **构型（图算法 + JEV）**：在 act 边构成的有向带类型图上找候选：链（有向路径 3–4）、环（有向环 3–4，且两两互惠弱）、团队（发起人的角色缺口 → 每个角色 K 选一挑人 → 指派）、一对多（同类 act 边的中心）、多对多（二部稠密子图）。每个候选构型整体作为材料再判一次（读数跨题不可加，不用两两相乘）；成长循环：「加入此人会不会让合作更紧密」打分做变式，不再进步即停。
- **构型再组合**：判定成立的构型生成「能提供/还缺」，作为节点进入召回与判断。
- **方案（生成，只在筛选后）**：只对前 K 个构型调生成器写详细合作方案（谁出什么、分工、节奏、风险、置信度来源）。
- **持续性**：agent 加入、离开、披露变化都是事件；live 依赖图决定重算范围；读数变化以 `edge`/`config` 事件流出，同时更新该 agent 的「可发现表示」（进行中的关系读数进入它的召回向量 → 计算改变可发现性）。

## 四、规模

每次接入：编码 1 次，ANN 3 路，两两判断 ≤ k 个 state（k≈32，合批后 ≤ 32 次调用），构型判断 ≤ 10 次，补信息 ≤ 若干轮。调用数与 N 无关；时延由 32 并发 ≈ 35 次/秒决定，目标首批机会 ≤ 15 秒。1 万规模用「N=500/2000/10000 下各实测数十次接入」给曲线，不做全量真机。
