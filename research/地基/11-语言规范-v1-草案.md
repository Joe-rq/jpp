## 0. 范围与设计原则

Jv 是一门**判断语言**：程序由守卫命令 `g → S` 组成，g 是 Jev 的一道校准三值判断，S 是绑定的确定函数。
唯一的非确定运算是判断；其余全是确定性代码。程序可逐字节重放。[08 §2；推导 ← P3]

原则（每条引账本）：
1. **字面化定律**：每道判断必须对面前的材料一跳可判；不字面的先由 S 变字面。[推导 ← P1、P10、P16]
2. **三种数字化**：判出位、选出索引、量出档；程序只能被这三种驱动，故三种题完备且最少。[06 §6；推导]
3. **语义操作与题型分离**：源码写 test / select / measure，题型（noul / choice / score）由编译器按实测表下沉。[推导 ← E9b、E10]
4. **融合与裂变**：同渲染状态同层的题合成一次请求 [P5]；超窗状态按窗切开 [P4]。这是编译器的两个核心 pass。
5. **读数不可表达**：语法里没有概率；线只来自校准。[推导 ← P1、D2；选择 | 消融：允许字面量线则 E4 纪律失效]
6. **unsure 是一等出口**：每个守卫必须写去向，或使用带固定去向的组合子；没有静默二值化。[推导 ← P2；研究 §5.2]
7. **成本以预算进、以计划出**：`budget` 必填，`jv plan` 逐语句报层与钱；成本不以程序结构出现。[J2 §5]
8. **一状态一对象**：对象槽单独占位；多对象同状态待 E16。[P4、A7]
9. **任务无关**：语言只关于自己的逻辑；任务清单只是探针。[宪法附则]
10. **有界迭代，账本只增**：无不动点。[推导 ← P2、P4]

## 1. 词法

- 编码 UTF-8；标识符：Unicode 字母或下划线开头，可含数字；中文可作标识符。
- 关键字：`program budget q s pure do let if else unsure select as switch case while bound improving decreasing increasing host choose for in yield partition loop refine escalate drop return import state on ctx over ref anchors probes fail`
- 题式关键字：`attr rel subset enough cmp class mention decide degree`
- 字面量：字符串 `"…"`（题面、实现路径）、整数、金额 `$0.10`、时长 `30s`、集合 `{a, b}`、档位序列 `低 < 中 < 高`。
- **没有概率字面量，没有数值比较运算符作用于判断。**
- 注释 `# …`。

## 2. 语法（EBNF）

```
program   ::= "program" ID "(" params? ")" "->" type "{" budget decl* stmt* "}"
params    ::= ID ":" type ("," ID ":" type)*
type      ::= "Mat" | "Set" | "Q" | "Scale" | "Map" | "Int" | "Str" | type "⊎" "fail"
budget    ::= "budget" bitem ("," bitem)*                       # 必填
bitem     ::= "calls" "<=" INT | "cost" "<=" MONEY | "layers" "<=" INT | "time" "<=" DUR | "escalate" "<=" INT

decl      ::= qdecl | sdecl | "import" STRING
qdecl     ::= "q" ID ":" form "=" STRING ("probes" STRING)?
form      ::= "attr" | "rel" | "subset" | "enough"                     # → test（位；subset 出位向量）
            | "cmp" | "decide" | "mention" | "class" "[" ID ("," ID)* "]"  # → select（索引；class 静态标签）
            | "degree" "[" ID ("<" ID)+ "]" "anchors" ID                # → measure（档；锚必填）
sdecl     ::= "s" ("pure" | "do") ID "(" params? ")" "->" type "=" STRING

stmt      ::= "let" ID "=" expr
            | "if" call block ("else" block)? unsure
            | "select" call "as" ID block unsure
            | "switch" call "{" ("case" ID block)+ "}" unsure
            | "while" variant "bound" INT block unsure
            | "choose" "{" (call "->" block ";")+ "}" ("else" block)? unsure
            | "loop" "bound" INT block
            | "do" call | "refine" expr | "escalate" expr | "drop" expr | "return" expr | call
variant   ::= "host" expr ("decreasing" | "increasing") | call "improving"
unsure    ::= "unsure" "->" dest ("then" dest)? | "unsure" block
dest      ::= "escalate" | "refine" | "drop" | "continue" | "regen" | "anchor" | "skip"
call      ::= ID "(" slotarg ("," slotarg)* ")" | ID "(" args? ")"
slotarg   ::= ("on" | "ctx" | "over" | "ref") ":" expr
block     ::= "{" stmt* "}"
expr      ::= ID | STRING | INT | set | call | expr "with" expr | expr "." ID
            | "for" ID "in" expr "yield" expr                        # 纯映射，无外层写
            | "partition" call "over" expr                            # 三流：act / ignore / unsure
            | "state" "(" slotarg ("," slotarg)* ")"
set       ::= "{" (expr ("," expr)*)? "}"
```

题的调用 `call` 用具名槽：`on` 对象（必填，除 `cmp/decide/class/mention` 可只给 `over`）、`ctx` 语境、`over` 候选集、`ref` 参照。
状态由编译器按四槽构造；程序员不拼字符串。`state(...)` 只在需要把状态当值传递时显式写。

## 3. 类型

### 3.1 值类型
- `Mat`：唯一材料类型。带地址、来源链（about、made_by）、渲染函数。出口是 `Mat` 的子类型。[选择 | 消融：多类型则来源链与账本键分裂]
- `Set` = `Set[Mat]`；`Map` = `Map[Mat, 出口]`（对象槽是集合时的向量化结果）。
- `Q`：题，一等值。可赋值、入集合、作候选集。携带：题面、题式、语义操作、验题路径、校准 id。[推导 ← 10 §2「决定/下一问」需要题为候选]
- `Scale`：刻度，一等值。携带档位序列与锚指纹。
- `Mat ⊎ fail`：`do` 函数的返回类型；`fail(原因)` 走 unsure 流并入账。[红队 04 盲点 1]

### 3.2 读数与出口
- 读数 `R_test[q]`、`R_select[q, C]`、`R_measure[q, L, anchors]` **不出现在语法里**。唯一能看见读数的地方是 `jv replay`。[推导 ← P1、D2]
- 出口：`Outlet3 = {act, ignore, unsure}`；`Chosen[q, C] = C ⊎ {unsure}`；`Level[q, L] = L ⊎ {unsure}`。
- `subset` 的出口是 `Map[候选, Outlet3]`。

### 3.3 类型规则（编译期错误）
| 代码 | 规则 |
|---|---|
| E1 | 判断没有值：守卫只能出现在 `if/select/switch/while/choose` 或组合子里 |
| E2 | 跨候选集比较 `Chosen`；跨刻度或异锚比较 `Level` |
| E3 | 守卫缺 `unsure` 去向 |
| E4 | 守卫位出现数值、比较或概率 |
| E5 | `degree` 缺 `anchors` |
| E6 | `while` 缺 `bound`；`loop` 缺 `bound` |
| E7 | 状态渲染超窗口（材料编译期已知时）；`switch` 未恰好覆盖 `class` 标签 |
| E8 | `for … yield` 体内对外层变量赋值；`do` 无法按数据依赖定序 |
| E9 | `degree` 的状态含同伴（`ctx`/`over` 含同种类候选）却被排序 |
| E10 | `budget` 缺失；`escalate` 无预算 |

跨材料的合法运算只有一处：同题同刻度同锚、且状态不含同伴的 `Level` 可做**偏序**排序（相邻档视为并列）与按档计数聚合。期望只在调试器显示。[推导 ← P2、P13、E10]

## 4. 语义

### 4.1 判
`o = outlet_q( jev( render(state), phys(q) ), calib(q, phys, kinds) )`。
- `render` 按四槽格式（§4.9）渲染，格式版本号进账本键。
- `phys(q)` 由编译器下沉（§5.1）；`calib` 的键 =（题面，对象槽种类，语境槽种类，物理题型，渲染版本）。[红队 04 盲点 4；J3 §6.4]
- 账本键 =（渲染状态哈希，题 id，物理题型，置换种子，渲染版本）。**按题不按题组**，融合不改变键。[P3；J2 §3]

### 4.2 三种控制流
- `if q(...) B₁ [else B₂] unsure U`：act → B₁；ignore → B₂；unsure → U。
- `select q(over: C, ...) as x B unsure U`：对 C 做记账置换 r 次（默认 2；长候选自动改逐候选 noul 取 argmax），众数 c 且线过 → x = c, B；否则 U。
  `switch` 是 `class` 静态标签集的 `select`，分支表恰好覆盖。
- `while 变式 bound n B unsure U`：变式两种：`host e decreasing|increasing`（宿主计量，严格单调）或 `q(...) improving`（打分档位不下降）。
  **进步判据**：宿主变式严格单调；打分变式档位不下降**且**（渲染状态，题）键在本循环内不重复。键重复 → 本轮出口 unsure 并退出，记账。[推导 ← P2 非单调；J3 §5 反例；红队 03 B3]
  `bound n` 到 → 退出，出口标 bound。

### 4.3 多守卫同真（08 §2 原文，三套都漏）
`choose { g₁(...) -> B₁ ; g₂(...) -> B₂ ; … } else B_e unsure U`：
同状态融合问全部守卫；恰一条 act → 走它；多条 act → 由一道 `cmp` 题（候选 = 启用命令的字面描述）决定走哪条；全 ignore → B_e；无 act 且含 unsure → U。

### 4.4 复合守卫
`if a(...) ∧ b(...)`：融合问全部子题，按强 Kleene 合成（有 ignore 即 ignore；无 ignore 有 unsure 则 unsure）；`∨` 对偶；`¬` 只对出口对调并标注，不是反问。
嵌套 `if` 是短路语义，**不**宣称与复合等价。[J3 §5 L1 反例]

### 4.5 集合与顺序
- `for x in S yield e`：纯映射，体内不得写外层变量（E8）；元素间独立，同层判断由调度器融合并发。
- `partition q over S`：返回三流 `(act 集, ignore 集, unsure 集)`。
- `loop bound n`：顺序循环，可写外层变量。
- `do` 按数据依赖定序，无依赖可并发；键 =（程序点，参数哈希，迭代索引）。

### 4.6 unsure 的去向（每槽两个有序去向，第一去向上限 2 次）
| 目标槽 | 第一去向 | 第二去向 |
|---|---|---|
| 材料 | 先问 `enough`（材料够回答吗）：不够且可拆 → `refine`；够 → 升级 | `escalate` |
| 语境 | 换语境（换一条定义/约定） | `escalate` |
| 参照 | `anchor`（加一条锚，参照库有） | `escalate` |
| 问题 | `escalate` | — |
| 候选集 | `regen`（绑定了生成器时再生成一批） | `escalate` |
| 刻度 | `anchor` | `escalate` |
| 动作 | 不执行，记账 | `escalate` |
| 循环 | 退出并记账 | — |

裸的 `if/select/while/choose` 必须显式写去向（`unsure -> refine then escalate`）；组合子（§6.4）在体内实现一次上表的去向，调用时不写。
每次按表走的去向写进账本与轨迹。`refine` 细拆到单段仍 unsure → 不得聚合成确定值，必升级。[红队 04 §6.3]

### 4.7 聚合子
位：`exists`（max）、`all`（min）、`count` 给区间 `[n_act, n_act + n_unsure]`。索引：`mode`（众数）、`hist`。档：`dist`、`median`、`top k`（k 内含 unsure 则标 unsure）。
混合聚合由宿主写，须显式处理 unsure 流。

### 4.8 S 与「做」
- `s pure`：无副作用，账本按输入哈希缓存；宿主承诺纯性，运行时抽查降为 warn。
- `s do`：触世界，返回 `Mat ⊎ fail`；重放取账本不重触世界。
- 生成器、执行器、渲染器、人（`ask`）都是 S；语言不为它们加原语。[08 §4]
- `⊤ → S`：不带守卫的纯段合法。

### 4.9 渲染格式（版本化）
```
[JVR 1]
[对象] …            # 恰一个对象；对象槽单独占位
[语境] …            # 可空
[候选 k=…] A) … B) …  # 仅 select；顺序按置换种子
[参照] 档1: … 档2: …  # 仅 measure；每档一条锚
```
格式版本号进账本键与校准键；渲染器一改，版本号递增，旧账本与校准按版本隔离。[红队 04 盲点 5]

### 4.10 升级（escalate）
带预算（`budget escalate <= n`）与去重（同键只问一次）；超预算的 unsure 转为「保留并标注」；人答回流后同题同材料的其它 unsure 自动复用；人答进校准集。[红队 04 盲点 2]

## 5. 编译

### 5.1 下沉表（校准库里的实测表，不是编译器常量）
| 语义操作 | 条件 | 物理题型 | 依据 |
|---|---|---|---|
| test（attr/rel/enough） | — | noul | D2 |
| subset | K 候选 | K 道 noul（Jev 多选待查 D1） | 红队 04 盲点 8 |
| select（cmp/decide/mention） | 段落级候选，K ≤ 16 | choice，置换 2 次取众数 | E10 P12 |
| select | 代码级候选，K ≤ 4 | choice，置换 2 次 | E9b P17 |
| select | 代码级候选，K > 4 | K 道 noul 取 argmax | E9b |
| select | K > 16（段落级）或 > 255 | 分组 + 锦标赛 | D1 |
| class | 静态标签 | choice | D1 |
| measure（degree） | 档 ≥ 3 | score，锚每档 1 条 | E10 P13 |
| measure | 档 = 2；select K = 2 | 假设：≡ noul（未测，编译器不据此下沉） | J3 §6 |
`jv lower` 打印每题命中的规则与依据。表可被校准库更新。

### 5.2 融合
同渲染文本逐字节相同、同层的全部题 → 一次请求。多条规则要进同一状态只能进题面（每条一道题），不进语境槽。[红队 04 A1-3]

### 5.3 裂变与合回
超窗（noul 500 带主张、choice 段落级 1.8k、代码级 1.5k，均为**下界**）时按窗切开，对象单独占位；合回规则按语义操作：
test → exists = max（或按声明 all）；select → 分块选再锦标赛；measure → 按出口计数。`jv plan` 标「待测上限」。

### 5.4 规划器
目标：在「每状态 ≤ 窗口」与 `budget` 约束下，按（层数，钱）字典序最小。层间顺序按 rank = (σ − 1) / 代价；加一元筛值得当且仅当 N_s > K / (w(1 − σ²))。
层边界重规划（实测幸存率偏离预估 > 2 倍）。并发按状态大小自适应（大状态降并发，E10 SSL EOF）。
可静态估计的笛卡尔积报 W-cost 并要求显式 `allow pairs`。

### 5.5 干跑报告
`jv plan` 输出与源码逐语句对齐的旁注：`层 n · 调用 k · 下沉 choice/K-noul · 裂变 m 块 · 预估 token · $ · s`，并与 `budget` 比对；超阈值（默认 $0.10）要 `--confirm`。

## 6. 标准库

### 6.1 S 库（先于题库）
五类接口：取（file/http/repo）、跑（run/bench/test）、算（features/diff/ast/log_stage/union_find）、抽（sample/neighbors/split）、渲染（a11y/ocr/table）。
登记一行：`s pure|do 名(参数) -> 类型 = "路径"`；实现是任意语言的可执行文件，I/O 是 Mat 序列化。切分/装槽/查窗/记键由编译器内建。

### 6.2 题式模板（七 + 二）
attr、rel、cmp、class、mention（原「解释」，按一跳改写：「x 的文字里出现了 h 描述的原因吗」，溯因由宿主组合）、degree、decide（含「下一问」）、subset、enough。
写题四规则由检查器守：一跳字面（题库审核）、一题一对象（E9）、候选集穷尽或带「都不是」（常驻候选集）、量必有锚。

### 6.3 参照库
`degree` 的锚（每档 1 条，指纹进类型）；`class`/`cmp` 的「都不是」模板；锚的来源之一是「档→参照」映射（某档典型样例入库）。

### 6.4 组合子（固定去向，调用时不写 unsure）
三种映射 × 目标槽，作为库程序发布，体内实现 §4.6 去向一次：
```
gate(q, S) -> Set                 位→材料门；unsure：enough → refine / escalate
run_if(q, m, S: do)               位→动作门；unsure：不执行记账
take(q, C, ctx) -> Mat            索引→材料；unsure：regen（有生成器）/ escalate
route(q, Qs: Set[Q]) -> Q         索引→问题（二阶）；unsure：escalate
dispatch(q, A: Set[do]) -> Mat    索引→动作；unsure：不执行
rescale(q, scales: Set[Scale])    索引/档→刻度；unsure：anchor / escalate
threshold(q, S, 档) -> Set        档→材料；unsure：refine / 入 unsure 流
allocate(q, S, plan)              档→动作（判断力分配）；unsure 档按最低档分配
retitle(q, Qs_by_level)           档→问题；unsure：escalate
```
三种映射的本质只有门（位）、路由（索引）、阈序（档）；上表是它们落到各槽的具名形式，表是文档，原语是三种。[红队 04 §6.2]

### 6.5 骨架（用 Jv 写）
`filter`（partition）、`pick`（select 含置换）、`rank`（偏序，状态只放锚与对象）、`tournament`（unsure 组晋级前二；整组 unsure 再置换一次再放弃）、`divide`（拆块→出口摘要→再判）、`search`（做→观察→判→定→做，带已访集合、不可逆闸门）、`choose_then_verify`（选型：预测 + 事后回填）、`derive`（二阶：用 `route`/`decide` 在带标签样本上选题，条件于目标）、`preview`（[假设 #24]，验收：稀有目标召回 ≥95% 且调用 ≤30%）。

### 6.6 冷启动与校准状态
题的校准状态：`冷`（无验题：保守默认线 hi 0.75 / lo 0.25，所有出口带「未校准」标记，累计 20 条人答自动转入验题）→ `上岗` → `停岗`；`待真值`（预测类，真值到达后算错误率）。[红队 04 盲点 3；08 §6]

## 7. 工具链与诊断

- `jv check`：E1–E10 与 warn（W-cost、W-P4 语境槽含多份带主张材料、W-fission、W-drop 隐式丢弃、W-noprogress 静态子集）。
- `jv lower`：每题下沉结果与依据。`jv plan`：§5.5。`jv run --budget`：分层、并发自适应、五道终止（深度、键重复、bound、钱、升级预算）。
- `jv replay run --layer n`：该层每题读数、选择分布、档位分布、置换前后 argmax、按表走的 unsure 去向。viewer 显示分布，不只出口。

## 8. 校准分题型

- test：hi/lo 两条线，δ 0.05，验题 3 act + 3 ignore，缝 ≥ 0.20；停岗 n ≥ 20 且错误率 > 2ε。
- select：置换一致率 ≥ 97% 才上岗；每选项 3 题 + 「都不是」3 题；线₂ 不设硬下限，从标注数据按 K 扫描；unsure 率 > 30% 的 K 禁用。
- measure：每档 3 题；锚指纹进类型与账本键；相邻档差 < 0.15 → unsure；批不变性 0.90 → 状态不放同伴。
- 校准键 =（题面，对象槽种类，语境槽种类，物理题型，渲染版本）；下沉改变即换线。
- 错误率带区间：n ≥ 20 报 ±10%，n ≥ 73 报 ±5%。线只从标注数据来，禁止手调。

## 11. 为什么（每章的设计决定：起点 → 推理 → 落点，标来源）

- **§0 以守卫命令式为骨**：起点是三评审一致（J1 交互类唯一可读；J2 判键粒度唯一正确；J3 与 08 一致、翻版风险最低）。推理：能做域要扩的是构造与交互任务，声明式与数据流在那里最弱。落点：L1 骨，L2/L3 嫁接。
- **§2 题式为首词、槽具名**：起点是 J1「消掉手拼状态」与 10 §2 题式表。推理：题式决定语义操作与下沉默认，槽由编译器装，程序员不拼字符串（P4 对象绑定由编译器守）。落点：`q 名 : 题式 = "题面"`，调用 `题(on:, ctx:, over:, ref:)`。
- **§2 `for … yield` 纯映射 + `loop`**：起点是红队 04 A1-1（for 无序与体内改变量矛盾，9 条探针确定性不成立）。推理：并发折叠要可交换，语言只能承诺纯映射；要顺序就 `loop`。落点：E8。
- **§4.2 `while` 的进步判据**：起点是红队 04 A1-2（`< 最低档` 永不执行）与 J3 L2 反例（严格单调 4 轮必停）。推理：打分变式在 δ 下不能严格单调，用「不下降且键不重复」；宿主变式可严格单调。落点：两种变式。
- **§4.3 `choose`**：起点是 J3 指出三套都漏 08 §2「多守卫同真由选择题解」。落点：新语句。
- **§4.4 复合守卫**：起点是 J3 L1 反例（嵌套与 Kleene 矛盾）。落点：显式 `∧`，嵌套明确为短路。
- **§4.6 ? 去向两个有序**：起点是红队 04 §6.3（固定单一去向造成确定假阴性与死循环）。推理：第一去向失败必须换路，且材料格先问充分性。落点：表 + `then`。
- **§3.1 题与刻度一等值**：起点是 J1/J2 共同缺四格（路由、换刻度、缩放、分配）。推理：目标槽是问题或刻度时，映射的值域必须是值。落点：`Q`、`Scale` 类型。
- **§6.4 三映射 × 槽而非 16 组合子**：起点是红队 04 §6.2（API 爆炸；本质只有门/路由/阈序）。落点：三原语，具名形式是库。
- **§4.1 校准键含物理题型与材料种类**：起点是 J3 §6（下沉换题型必换线）与红队 04 盲点 4（题面跨种类共用线）。落点：五元键。
- **§4.9 渲染格式版本化**：起点是红队 04 盲点 5。落点：`[JVR 1]` 与版本入键。
- **§4.8 `fail`**：起点是盲点 1（E9b 写手 30% 超时）。落点：`Mat ⊎ fail` 走 unsure 流。
- **§4.10 升级预算**：起点是盲点 2（unsure 率 20% 时升级不可能 O(1)）。落点：预算 + 去重 + 复用。
- **§6.6 冷启动**：起点是盲点 3（15 条探针第一天一条也跑不了）。落点：`冷` 状态与未校准标记。
- **§5.1 下沉表为实测表**：起点是 J2（阈值是两点插值）。落点：校准库存表，`jv lower` 打依据。
- **§5.2 融合只对逐字节同状态**：起点是红队 04 A1-3（多规则塞语境违反 P4）。落点：规则进题面不进语境。
