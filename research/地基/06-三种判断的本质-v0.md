# 三种判断的本质 v0 · 按挖是非题的路数再挖两遍

日期 2026-09-20 深夜。Nature 指出昨晚全部构建只用了是非题，组合层被锁死。
挖是非题时走的路是：原语是什么 → 三个基本操作（投什么、问什么、数字怎么反应）
→ 什么材料有价值 → 递归 → 一切是数据 → 任务无关自检 → 红队与数字。
本文对 choice 和 score 各走一遍同样的路，最后写三者合起来是什么。
未测的地方标「待测」，不冒充证据。

## 0. 三种题各是什么运算

| 题型 | 输入 | 输出 | 运算 | 程序语言里的对应 |
|---|---|---|---|---|
| noul 是非 | 状态 + 一个命题 | 一个概率 | 一元谓词 | `if` |
| choice 选择 | 状态 + K 个候选 | K 上的分布，Σ≈1 | **比较 / argmax** | `switch`，分支 |
| score 打分 | 状态 + 一个刻度 | 档位上的分布 | **有序度量 / 目标函数** | `while score < 目标`，排序 |

是非题只能筛。选择题给语言**分支**。打分题给语言**程度和循环的进度**。
三者合起来是一个优化问题的全部要素：约束（是非）、选择（选择）、目标函数（打分）。

## 1. 选择题

### 1.1 原语
一个状态里放 K 个候选，一次调用，返回每个候选被选中的概率，和约等于 1。
K 个候选**在同一个上下文里互相比**，所以影响全部候选的偏差在 argmax 上抵消。
这是相对判断优于绝对判断的机制（文献一致；待 E9 实测 Jev 自己）。
成本：一次调用装 K 个，每候选约 38 token，不是 K 次调用。

### 1.2 三个基本操作
- **投什么材料**：选择题有两个材料槽。**上下文**（候选被比的依据）和**候选集**。
  上下文的价值标准不同于是非题：不是「关系到 Q」，是「能把候选**分开**」；
  对所有候选同样成立的材料一点用没有。候选集的价值标准是**互斥且穷尽**：
  不互斥则 Σ≈1 没意义，不穷尽则必须加「都不是」选项，unsure 从这里来。
- **问什么**：判据。同一判据换候选集 = 锦标赛；同一候选集挂多个判据 = 多目标，几乎免费。
- **数字怎么反应**：argmax → 选中一个，进下一层；分布平 → unsure → 再生成或细拆；
  前 b 名 → 束搜索；分布本身不进 Jev，只有被选中的候选进。

### 1.3 什么材料有价值
证据 = 能区分候选的；语境 = 让候选读对的（同是非题）；
参照 = 候选集本身：换一批候选，同一个候选的概率就变。所以选择题的读数
**只在同一候选集内可比**，跨候选集比较是类型错误（P_q 的规则扩展到 P_{q,候选集}）。

### 1.4 递归
选择可以选选择：哪个问题最能分开这批样本（谓词推导的区分步）、
哪个骨架适合这个目标、下一层往哪个分支深入。锦标赛是选择的递归：
K 选一的胜者再 K 选一，深度 log_K N。

### 1.5 一切是数据
候选是材料，被选中的候选是材料，分布是读数（不渲染）。选项标签是材料。

### 1.6 任务无关自检
文档：哪段与 a 矛盾；代码：哪个补丁正确；computer use：该点哪个入口；
Agent：哪个方案满足约束。四个任务的选择题只有判据和候选来源不同。通过。

### 1.7 已知失效（文献，待测 Jev）
位置偏差（换序改判，一手证据见研究/02）、长度偏差、候选数上限、
近似平局、候选集不穷尽。对策：候选顺序随机置换并聚合；校准线两条
（最大概率下限、前二差距下限）从标注数据来；每题记选中位置分布。

### 1.8 它让语言多出什么
分支。锦标赛。分类（固定标签集的选择题 = K 类分类器）。路由。
把生成器切出的互斥穷尽解空间逐层选下去 = 暴力求解。`find x : J(x)` 的实现。

## 2. 打分题

### 2.1 原语
一个状态，一个刻度（有序档位），返回档位上的分布，附期望与不确定性。
它是**绝对但有序**的度量：每个东西单独打分，但分数之间可以排序。
所以 N 个东西排序只要 N 次调用，不要配对，不要锦标赛。O(N)。

### 2.2 三个基本操作
- **投什么材料**：被打分的东西 + **参照**。刻度必须锚定：每档一个样例进状态，
  否则分数随每次状态漂移，跨东西不可比。参照必须在每个状态里一样，
  这是打分题特有的批不变性要求（待测：同样例不同批次的读数差）。
- **问什么**：刻度的定义。档数（3/5/10）、每档的字面含义必须一跳可判。
  档太多则相邻档分不开（待测：档数与相邻档区分力的关系）。
- **数字怎么反应**：过某档 → 带程度的过滤；排序 → 前 k、优先级；
  分布双峰 → unsure；同一题跨东西的期望**可以比较和聚合**（同 P_q，合法），
  得到整批材料的度量（平均紧急度、随时间的趋势）。

### 2.3 什么材料有价值
证据、语境同前。参照在这里从「第三类」升为**必需**：没有参照就没有刻度。

### 2.4 递归
打分可以打分打分：对读数的可信度打分（校准的自评，待测是否有信息）；
对材料的价值打分（「这段对判断 Q 有多大帮助」是打分不是是非，
E8 元题失败可能部分因为用了是非题，待测）。

### 2.5 它让语言多出什么
- **程度**。是非和选择都没有「多」。
- **目标函数**。生成加判断的循环需要的不只是过/不过，是分数在涨还是跌。
  有了打分题，搜索从「接受/拒绝」变成**爬山**：保留分数更高的变异。
  进化搜索、模拟退火、束搜索的适应度都由它给。
- **进度**。`while score < 目标` 是判断驱动的循环条件，有界迭代终于有了停机的语义依据。
- **剂量反应**。同一东西、材料逐步加，分数曲线 = 材料对判断的影响量。
  红队说差值法被噪声混淆，但打分题档位粗、迟滞 0.15 已测，大的移动能测出来（待测）。
- **预算分配**。分布散的东西值得再判，集中的不用（主动学习的不确定性采样，研究/01 §4.2）。

### 2.6 任务无关自检
文档：这段多重要；代码：这个补丁风险多高；computer use：离目标多近；
Agent：这个方案满意度多高。只有刻度和参照不同。通过。

### 2.7 已知失效（待测）
无参照时漂移；档数过多相邻不可分；长度偏差（长的显得「多」）；
批不变性是否成立；期望值是否可跨批比较。

## 3. 三者合起来是什么

一个搜索或优化问题由三样东西定义：可行域、目标、选择规则。
- 是非题判**可行**（约束满足吗）。
- 打分题给**目标值**（多好）。
- 选择题在可行候选里**选**（相对判断，抵消共模偏差）。
加上生成器出候选、「做」拿观察、有界迭代做循环，任何经典搜索算法
（束搜索、进化、分支限界、蒙特卡洛树搜索）都能用这几样写出来，
目标和约束用自然语言写，执行确定性、可重放、带校准错误率。

控制流因此完整：`if`（是非）、`switch`（选择）、`while`（打分）。
昨晚的语言只有 `if`，所以只能筛。

## 4. v3 内核要改成什么

- 类型：材料 M；读数三种 R_noul,q / R_choice,q,候选集 / R_score,q,刻度。
- 桥三座：→ {act, ignore, unsure} / → 候选 ∪ {unsure} / → 档位 ∪ {unsure}。
- 算子七个：过滤、**选**、**序**、配对、聚合、有界迭代、做。
- 骨架五个：筛、配对、分治、搜索、**锦标赛**。配对的一部分被「选」吸收
  （对每段 a，一个状态放 a + K 段，问哪段与 a 矛盾，N²/2 → N·N/K）。
- 校准：三种题各自的线，全部从标注数据来。

## 6. 再想一层（2026-09-21，总控自己的思考）

**三种题是判断的三种数字化。** 确定性程序只能被三种东西驱动：一个位（走不走）、一个索引（走哪条）、一个数（走多远、先走谁）。
是非题给位，选择题给索引，打分题给数。结构化程序只需要顺序、分支、循环（Böhm–Jacopini），
分支吃位或索引，循环吃数。所以三种题对「驱动程序」是完备的，也是最少的：少一种就有一类控制点没法由判断驱动。
这是「为什么恰好三种」的回答，不靠 Jev 文档，靠程序的结构。

**选择题的本质是关系判断。** 是非题判一个东西对一个命题，选择题判一组东西彼此之间在同一上下文里的关系。
由此它的用法不止「选候选」：
- 选材料：「这 16 段里哪段和 a 矛盾」，一次调用代替 16 道是非（E10 已测 K=16 可行）。选择题是语言里的注意力。
- 消歧：一道题有几种读法，让 Jev 选读法，再问。
- 分类：固定标签集的选择 = K 类分类器。
- 决定：有限个动作里选一个，它是唯一输出直接就是动作索引的题。
- 解非确定：多条守卫同真时选哪条（08）。
生成加暴力求解只是「决定」的一个实例。

**打分题的本质是把判断变成数。** 它是语言的模数转换器：Jev 不做算术，但打分题的档位进了宿主之后，
宿主可以合法地算（同题同刻度同锚、单独渲染，E10）。所以凡是需要「多少」的地方都是它：优先级、阈值带程度、
变式（循环进度）、把判断力花在哪（分布散的再判）、搜索的方向（分数涨跌）、一批材料的度量（档位分布随时间的曲线）。

**组合的基本形。** 同一个状态一次调用可以同时要三种：对一组候选，每个一道是非（可行吗）、每个一道打分（多好）、
一道选择（哪个最好）。一次往返给出约束、目标、决定三样，题免费。这就是优化问题的三要素在一次调用里同时成立。

**语言层的推论：语义操作与物理题型分开。** 程序员写的是三种语义操作：test（判）、select（选）、measure（量）。
它们各自可以有不止一种物理实现：select 可以下沉为一道选择题，也可以下沉为 K 道是非取最高；
E9b 证明长候选下后者更准（首位偏置 33% 对 0），E10 证明短候选下前者足够且省调用。
所以**选哪种题型是编译器的事，按 K、候选长度、已测偏置决定**，像数据库的逻辑算子与物理算子。
编译器还做两件事：**融合**（同状态的所有语义操作合成一次调用，P5）和**裂变**（材料超窗时按窗口切开，P4）。
融合与裂变是这门语言的编译器区别于任何现有编译器的核心工作，它们直接来自 Jev 的两条公理。
这一条要填进宪法登记表（借：数据库逻辑/物理算子；条件变化：物理算子的代价与偏置由 Jev 实测决定，且同状态多算子可免费融合）。

## 7. §6 各条的来源（为什么这么想）

- 「三种数字化」：起点是问自己「为什么恰好三种，而不是两种或四种」。从 Jev 文档只能答「文档就这三种」，那不是理由；
  换成从程序这边问「程序能被什么驱动」，答案是位、索引、数，与三种题一一对应，这才是理由。Böhm–Jacopini 只是确认它够。
- 「选择题是关系判断」：起点是 E10 的注意题（哪段与 a 矛盾）跑通，意识到选择题选的不一定是候选，可以是材料；再问「还能选什么」，数出七种。
- 「打分题是模数转换器」：起点是红队 03 A2 与 v0「不用衍生量」的冲突。解法是把算术的责任划给宿主：Jev 给档，宿主算，这正是 ADC 的分工，
  E10 定了它成立的条件（同锚、单独渲染）。
- 「语义操作与题型分离」：起点是 E9b 与 E10 的矛盾——同样是「选」，长候选用 K 道判更准，短候选用一道选更省。
  两条实测指向同一个结构：源码写语义，编译器选题型。数据库的逻辑/物理算子是最近的先例，按宪法填了登记表，第三格是「代价与偏置由 Jev 实测决定」。
- 「融合与裂变」：融合直接来自 P5（题免费、状态收费），裂变直接来自 P4（窗口）。它们是编译器的两个核心 pass，因为它们是仅有的两条影响成本的公理。
