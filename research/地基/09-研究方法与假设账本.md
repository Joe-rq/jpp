# 研究方法与假设账本 v0

日期 2026-09-21 凌晨。Nature：现在讲的这些都不是固定的、不是推导出来的；要有科学的研究方式，
才能推导出加什么、基本单元是什么。本文定方法，并把到目前为止的每一个主张登记进账本，
标明它是公理、推导、选择还是假设，以及它的检验状态。以后每个主张进设计前先进这本账。

## 1. 方法

把语言当成一个**理论**来建。理论有公理、推导规则、定理、以及对定理的检验。

**公理 = Jev 的已测事实。** 只有量出来的才是公理；官方文档写明的算「文档事实」，同样可引。
不可从公理推出的东西不是定理，是**选择**，选择必须通过消融（去掉它会坏什么）才能留下。
凡是「我们相信但没量」的，是**假设**，必须先预注册再测，测完才能升级或作废。

**四种标签。**
- `[公理 Eₙ]`：已测事实，注明实验编号。
- `[文档]`：官方文档原文。
- `[推导 ← …]`：从公理/文档逻辑推出，写出前提。推导链断了就降为选择。
- `[选择 | 消融：…]`：不能推出、但要它；写出去掉它坏哪条验收。
- `[假设 | 检验：Eₙ / 状态]`：待测；状态 ∈ {未测, 测中, 成立, 证伪, 部分}。

**基本单元的三条判据（照公理系统的要求）。**
1. 完备：清单里每个效果（需求与启发清单 A–D）都能由单元集合表达。检验：31 条对照 + 100 任务表。
2. 独立：去掉任一单元，至少一个效果表达不出。检验：逐个消融（纸面 + 实跑，C §5 第 8 步）。
3. 一致：单元之间不互相矛盾。检验：红队找反例（如 A2 的 score 期望聚合与 v0 冲突）。
三条都过的集合才叫「基本单元」；目前没有一个候选集合三条都过。

**「加什么东西」的判据（超加性）。** 对候选技术 X，在同一任务、同一指标上测 f(Jev)、f(X)、f(Jev+X)。
只有 f(Jev+X) 显著大于 f(Jev)+f(X)（或成本显著小于两者之和的最小者）才叫 1000 分。
三个技术的 10000 分同理：f(A+B+C) 显著大于任一对。没有对照臂的比较不算数（红队 03 A4）。

**过程纪律。** 预注册 → 测 → 原样报 → 更新账本。红队每轮只打账本里标「推导」和「选择」的条目，
「假设」由实验打。设计文档只允许引用账本里状态为「公理」「推导」「成立」的条目；
引用「选择」要带消融理由；引用「假设」要标状态。

## 7. 方法补一条（Nature 2026-09-21）：怎么才能对

前提是潜力无限，工作是逼近它。所以账本里没有「证伪即终点」：
每一条证伪或部分的主张，必须附一栏**「怎么才能对」**——使它成立的条件、或要加的东西、或要改的定义。
已经这样做过的例子：过滤递归不收敛 → 配对与分治骨架；Jev 看不见运行时 → 字面化定律，先跑再判；
打分批不变性 0.90 → 状态不放同伴，偏序排序；元题无区分力 → 字面前提题；固定谓词表 → 条件于目标的推导。
实验的问题永远是「在什么条件下它成立」，不是「它成不成立」。红队的每条 A 类也必须带修法，无修法的攻击不收。

## 8. 目标不是搜索，是「能做域」的扩大与稳定（Nature 2026-09-21）

「Jev + 生成 = 搜索」只是一个机制的名字，不是目标。目标是两个量：
- **能做域**：在什么条件下判断驱动的程序成立。当前边界由 200 任务量出：五类锁（时延、模态、不可分解、真值不可观测、支持集外）加「无增益」。
- **稳定性**：在能做域内，错误率与翻转率有多低、随深度怎么累积（E1 δ、E9 首位偏置、E10 批不变性、待测 E14 串联翻转）。

所以「加什么东西」的判据改写：一项加入物的价值 = 它把能做域扩大多少 + 把稳定性提高多少，都要量。
按当前边界，每一类锁对应一种加入物：

| 边界 | 扩它的加入物 | 量法 |
|---|---|---|
| 支持集外 / 构造类任务（修到零矛盾、订行程） | 生成器 | 原来写不出的构造任务里，多少条能写并跑通 |
| 字面化不足（Jev 看不见运行时） | 执行器（做）、S 库 | 字面化后 AUC 的提升（E9b 对照臂） |
| 真值不可观测、边界案例 | 人（unsure 升级 + 校准回填） | 停岗率下降、线的置信区间收窄 |
| 模态 | 渲染函数（可访问性树、OCR、结构化抽取） | 模态锁里多少条回到文字且错误率可测 |
| 不可分解整体判断 | 分治骨架 + 出口摘要 | 近似与整体判断的一致率 |
| 时延 | 无（架构上只有离线批模式） | 标为域外 |
| 无增益 | 无（交给精确算法） | 标为域外 |
| 稳定性 | 置换、迟滞、校准、状态不放同伴、宁宽勿深 | 翻转率、错误率随深度的曲线 |

生成器的价值因此不是「能搜索」，是「构造类任务进入能做域」；执行器的价值是「字面化的覆盖面」；
人的价值是「稳定性随时间上升」。三者合起来的价值 = 能做域一次性扩大到「凡能变字面且能生成候选的构造任务」。
这才是 10000 分的定义，可量。

科学的做法就是这张表：每一格一个条件、一个加入物、一个量。工作是把「锁」一格一格变成「通」，
并把「通」里的错误率压低。
