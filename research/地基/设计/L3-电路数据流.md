## 1. 这是一门什么语言

JC 是一门把判断写成电路的语言。程序是一张有向图：节点只有两种，**Call**（一个状态上的一批语义操作，编译后是一次 Jev 请求）和 **S**（把世界变成文字的确定函数）；线只传材料，不传数字；图按**层**切开，一层等于一次网络往返。程序员写的是三种语义操作 test / select / measure，不写题型；编译器按候选数、候选长度和已测偏置把它们下沉为是非、选择或打分题，把同一状态上的操作**融合**成一次调用，把超窗的状态**裂变**成多个，然后算出每层的状态数、token、钱和秒，写在程序旁边。循环是带寄存器和变式的环，候选集是被扇出成 K 组的线，unsure 是每个 Call 必须接走的第三根线。它像硬件描述：结构就是成本，深度就是延迟，没有藏在运行时里的东西。

## 2. 部件，以及每个部件怎么用足 Jev

| 部件 | 是什么 | 为什么这样设计（引公理） |
|---|---|---|
| **Call 节点** | 一个 `state` 上的 1..n 个语义操作 `test / select / measure`；输出是**出口线**（act / ignore / unsure；pick；按档），不是读数。物理题型由编译器定（§2.1） | 成本单位是调用 [P5]，所以节点粒度=调用粒度；读数不出节点 [P1、D2 不做算术]；同一状态的多个操作编译期**融合**为一个请求 [P5：题近乎免费] |
| **S 节点** | 确定函数 `S.name(args)`，`effect none` 是纯变换，`effect world` 是「做」（跑、取、点） | 字面化定律 [推导 ← P1、P10]；执行后再判 AUC 0.79 → 0.95 [P16]；S 库不到 30 种就覆盖 100 个计算机任务 [设计/E] |
| **state 构造** | 四槽 `state(obj, cands, ctx, ref)`，逐元素向量化：`obj` 是 Set 时每元素一个状态 | 对象段单独占位 [P4 带偏]；窗口检查在此处：noul 500 / choice 段落级 1.8k、代码级 1.5k / score 每档 1 锚 [P4、E10]；打分状态**禁止**有同伴槽 [E10 批不变性 0.90] |
| **线** | 类型只有 `M`、`Set[M]`、`Map[Label,Set[M]]`、`Ranked[Scale]`、`Outlet` | 读数不可接线，跨题算术在语法上不存在 [推导 ← P(x)+P(¬x)≠1] |
| **层** `layer` | 一层内的所有 Call 同一往返；同状态合并、异状态并发 ≤ 32 | 时间 = Σ层 max(τ, 调用/35) [P5]；层就是 AQE 的物化点（登记表：查询规划器一行） |
| **扇出 / 配对 / 合并** `fan` `pair` `merge` | 纯宿主：`fan(S, K)` 把集合切成 K 组供 choice；`pair(A,B)` 笛卡尔积；`merge` 汇线 | 选择吸收配对 N²→N²/K [#13 成立，段落级 K≤16、代码级 K≤4 或走逐候选 noul，P17] |
| **环** `ring` | 寄存器 + 体 + 变式 + 上限；变式是打分题或宿主计量 | 有界迭代取代不动点 [推导 ← P2、P4]；变式=打分题做「重复」的位置 [08 §2]；无进展键重复即停 [红队 03 B3] |
| **汇** `sink` | `escalate`（升级给人，答案进校准集）、`drop`（显式丢弃并记账） | unsure 唯一合法去向：变字面或升级 [08 §2]；不接 unsure 是编译错 [研究 §5.2 SQL 教训] |
| **刻度与锚** `scale` `anchors` | 打分题的档位与每档一条锚样例，指纹进题的类型与账本键 | 3 锚已收敛，10 锚不再变 [P13]；无锚不可跨对象比较 [E10] |
| **预算** `budget` | 层数、钱、秒、调用数上限，编译期核对 | 「几秒几千次」只在 ≥20 题/次、≤5 层内成立 [P5 推论] |
| **账本与轨迹** | 每个 Call 节点的键 =（渲染状态，题，置换种子）；轨迹按层保存出口与分布 | 重放逐字节相同 [P3]；置换种子入账 [P9、P17] |

### 2.1 语义操作与物理题型分离；融合与裂变（`06` §6）

程序里没有 `noul / choice / score` 三个词，只有三种**语义操作**，对应程序能被驱动的三种数：

| 语义操作 | 意思 | 出口 | 编译器可选的物理下沉 | 选哪种（引实测） |
|---|---|---|---|---|
| `test q on st` | 判：对象对命题成不成立（位） | act / ignore / unsure | 一道是非题 | 唯一实现 |
| `select q among cands on st` | 选：一组东西在同一上下文里的关系（索引）。用法：选材料、消歧、分类、决定、解非确定 | pick / unsure（整组） | (a) 一道选择题，K 组一次调用；(b) K 道是非题取 argmax；(c) `labels{}` 静态标签集 → 一道选择题 | 段落级候选且 K≤16 → (a)（E10 一致率 1.00）；长候选（代码级）或 K>4 → (b)（E9b：首位偏置 33% 对 0，noul 14/14）；标签集 → (c) |
| `measure q scale L anchors A on st` | 量：把判断变成数（模数转换） | at(档) / Ranked（偏序）/ unsure | 一道打分题；或（档数 ≤3 且只要阈值时）一道是非题「≥ 档」 | 需要序或程度 → 打分（3 锚收敛，P13）；只要过线 → 是非 |

程序员也可以写 `phys: choice` 强制题型，但编译器在实测上限外会拒绝（W-K 升级为 E-K）。

**融合**：同一 `state` 上的全部语义操作，不论几种，合成一次 Jev 调用（题近乎免费，P5）。优化问题的三要素因此在一次往返里同时成立：对一组候选，`test` 每个可行吗、`measure` 每个多好、`select` 哪个最好，三条线同时出。融合是层的默认行为，不需要程序员做任何事。

**裂变**：`state` 渲染超窗时（noul 500 带主张 / choice 段落级 1.8k、代码级 1.5k / score 每档 1 锚，P4、E10），编译器把状态切开：`obj` 是集合就按元素分状态；`cands` 按 K 上限再分组并把 `select` 变成两层锦标赛；`ctx` 超窗则按窗切块、各块 `test`、把**出口**（不是读数）渲染成摘要接到下一层（分治骨架）。裂变增加层数，`jc plan` 会把它算进去。

融合与裂变是本编译器区别于任何现有编译器的两道核心 pass，各来自一条公理（P5、P4）。借用登记：借数据库的「逻辑算子 / 物理算子」分离；条件变化：物理算子的代价与偏置由 Jev 实测决定（E9b、E10），且同状态多算子可免费融合；新机制：按候选长度与偏置下沉 + 融合 + 裂变。

## 3. Jev 要加什么（从能做域表推）

| 加入物 | 在 JC 里是什么 | 扩能做域哪一格 | 怎么量 |
|---|---|---|---|
| 生成器 | `S.gen(prompt, n, avoid)`，`effect world`，返回 `Set[M]` 候选 | 构造类任务（修到零、订行程、生成命令） | 原来写不出的构造任务里可写且跑通的条数；E9c 题级通过率 [#22 部分] |
| 执行器 | 全部 `effect world` 的 S：`run_tests`、`sandbox_exec`、`compile`、`bisect_run`、`rerun` | 字面化不足 | 执行渲染后 AUC 提升（0.79→0.95，P16） |
| 人 | `sink escalate`；回答以 `M` 回流并写入校准集 | 真值不可观测、边界案例 | 停岗率、线的置信区间宽度 |
| 渲染器 | S 库的模态一族：`a11y_tree`、`ocr`、`table_to_text`、`ast` | 模态锁 | 模态锁里回到文字且错误率可测的条数 |
| 摘要 | `S.summary(Set[M])` 把一层的**出口**渲染成一段文字（不渲染读数） | 不可分解整体判断 | 近似与整体判断一致率（未测） |
| 选型回填 | `scale … pending`：题上岗时标「待真值」，`S.backfill(truth)` 到达后才算错误率 | 真值后到 | 回填后错误率是否在线内 |
| 域外 | 时延、无增益：编译器对 `budget time` 不可达的电路直接报「域外」 | — | — |

JC 不为这些加新节点类型：生成、执行、渲染、摘要都是 S；人是 sink。语言只多一个类型标记 `effect world` 与一个校准状态 `pending`。

## 4. 语言长什么样

### 4.1 词法
关键字：`circuit in out budget wire layer state test select measure labels among scale anchors phys on fan pair merge ring reg bound variant host until next sink escalate drop effect none world module import sfn pending`。题型词 `noul / choice / score` 只在 `phys:` 提示里出现。
标识符 `[A-Za-z_][A-Za-z0-9_]*`；题面是字符串字面量（中文可用，E-系列已测）；数值只出现在 `K=`、`bound`、`budget`、`n=`；**没有概率字面量**（线只能来自 `calib`，语法上不存在 0.65 这种东西）。

### 4.2 文法（BNF）
```
program    ::= (import | scale_decl | anchors_decl | sfn_decl | circuit)*
import     ::= "import" ModulePath
scale_decl ::= "scale" Id "=" "{" Id ("," Id)* "}" ("pending")?
anchors_decl ::= "anchors" Id "for" Id "=" RefLibPath
sfn_decl   ::= "sfn" Id "(" params ")" "->" Type "effect" ("none" | "world") "=" Binding
circuit    ::= "circuit" Id "(" params ")" "->" outs "{" budget? stmt* "}"
params     ::= ("in" Id ":" Type ("=" expr)? ("," "in" Id ":" Type ("=" expr)?)*)?
outs       ::= "out" Id ":" Type ("," "out" Id ":" Type)*
budget     ::= "budget" bitem ("," bitem)*
bitem      ::= "layers" "<=" Int | "cost" "<=" Money | "time" "<=" Sec | "calls" "<=" Int
stmt       ::= wire | layer | ring | connect | outassign | stop
wire       ::= "wire" Id "=" sexpr
sexpr      ::= "S" "." Id "(" args ")" | hostexpr | Id "(" args ")"        -- 子电路实例化
layer      ::= "layer" Id "{" (statedef | op)+ "}"
statedef   ::= Id "=" "state" "(" "obj" ":" expr ("," "cands" ":" fanexpr)?
                                  ("," "ctx" ":" expr)? ("," "ref" ":" expr)? ")"
fanexpr    ::= "fan" "(" expr "," "K" "=" Int ")"
op         ::= Id "=" ("test" Str | "select" Str selopt | "measure" Str "scale" Id "anchors" Id)
               ("phys" ":" ("noul" | "choice" | "score"))? "on" Id
selopt     ::= "among" "cands" | "labels" "{" Id ("," Id)* "}"
ring       ::= "ring" Id "(" "reg" ":" Type "=" expr ")" "bound" Int "variant" variant
               ("until" cond)? "{" stmt* next "}"
variant    ::= "host" hostexpr ("decreasing" | "increasing") | "measure" Str "scale" Id "anchors" Id
next       ::= "next" "reg" "=" expr
connect    ::= outlet "->" target
outlet     ::= Id "." ("act" | "ignore" | "unsure" | "pick" | "by_label" | "at" "(" Id ")" | "order")
target     ::= "sink" ("escalate" | "drop") | "merge" "next" "reg" | "out" Id | Id
outassign  ::= "out" Id "=" expr
stop       ::= "stop"
Type       ::= "M" | "Set[M]" | "Map[Label,Set[M]]" | "Outlet" | "Ranked[" Id "]" | "Int"
```
`hostexpr` 是纯宿主表达式（集合运算 `∪ \ ⊕`、`first`、`size`、`owner`、`members`），只作用于材料集合与整数，不作用于读数。

### 4.3 类型规则（编译期拒绝）
1. 语义操作的输出只有出口线；`q.p`、`q.dist` 不存在 → **读数不可接线**。跨题、跨候选集、跨刻度的比较因此无法写出。
2. `measure` 必须带 `scale` 与 `anchors`；`scale` 的锚指纹是题类型的一部分，换锚即新题。
3. `measure … on st` 的 `st` 不得有 `cands` 槽（打分状态不放同伴）[E10]。
4. `select … among cands` 的 `st` 必须有 `cands` 槽；物理题型由编译器按 §2.1 下沉，`phys: choice` 且 K 超实测上限（段落级 16、代码级 4）→ **E-K** [E10、P17]。`labels {…}` 是静态标签集，分支表由 `.by_label` 恰好覆盖。
5. 每个语义操作的 `.unsure` 必须恰好被一条 `connect` 消费（sink / merge / 后层 state）；否则 **E-unsure**。
6. `layer` 内的操作只能引用本层 `state`；`state` 只能引用本层之前产生的线；同层互引 **E-layer**。
7. `ring` 必须有 `bound` 与 `variant`；`next reg` 必填。
8. `state` 渲染超窗：可裂变（obj 是集合 / cands 可再分 / ctx 可切块）则编译器裂变并报 **W-fission**；不可裂变（单个对象自身超窗）且材料编译期已知则 **E-window**，否则运行期拒绝该状态并走 unsure。
9. 线只能来自 `calib`：语法无概率字面量；`budget` 里的钱与秒是宿主量，不是线。
10. `effect world` 的 S 节点之间按数据依赖定序；定不了序 **E-order**；环内按迭代顺序。

### 4.4 语义规则
- **下沉**：编译第一遍把每个语义操作定为物理题型（§2.1 表），记入计划；程序员的 `phys:` 只能在实测上限内生效。
- **层**：一层的全部操作打包；同一渲染状态的操作**融合**为一次请求，三种题型可混在同一请求里；超窗状态**裂变**（§2.1），裂出的层由编译器插入并在 `jc plan` 里可见；不同状态并发（≤32）。层的耗时是该层最慢的请求。子电路实例化后被**摊平**：编译器按依赖重算全局层号，程序里的 `layer` 只断言「这些操作同一往返」，若两层无依赖而分写，报 **W-mergeable**。
- **出口**：`outlet_q(读数, calib(q))`；`test` 出三线；`select` 下沉为选择题时默认 2 次记账置换，众数不一致或 `p_max` 不过校准线 → 该组进 `.unsure`（整组），否则胜者进 `.pick`；下沉为 K 道是非时取 act 中读数最高者为 `.pick`，无 act 或最高两者在 δ 内 → `.unsure`；`measure` 出 `.at(档)` 与 `Ranked`（偏序：同题同锚、单独渲染，|ΔE|<0.1 档并列）；含同伴的打分只允许 `.at`。
- **环**：每轮跑体，然后算变式：`host` 变式由宿主计量（数字不进 Jev）；`measure` 变式对 `S.summary(reg)` 一个状态问一次（多占一层，编译器在状态相同时并入体的末层）。停机条件（任一）：`until` 成立；`bound` 到；变式不再按声明方向变化；同一环内出现重复的（渲染状态，题）键——该轮出口记为 unsure 并退出。
- **汇**：`escalate` 把材料与题送人，人的答案作为 `M` 回流到同名线并写入校准集；`drop` 记账后丢弃。
- **确定性**：Call 键 =（渲染状态，题集，置换种子）；`effect world` 键 =（动作，序号），重放用记录的观察；桥之后纯宿主。重放逐字节相同 [P3]；新鲜运行读数差在 δ 内 [P2]。
- **模块**：`module` 文件含 `sfn`、`scale`、`anchors`、`circuit`；`import` 后子电路以 `Name(args)` 实例化，接口 = 入线类型 × 出线类型，与 Call 同形（组合的组合）。

## 5. 标准库

### 5.1 骨架（都是 circuit，可直接实例化）
| 骨架 | 签名 | 结构 |
|---|---|---|
| `Filter` | `(items: Set[M], q: Str, ctx) -> act, ignore, unsure` | 一层 noul |
| `Pair` | `(A, B, qs: [Str]) -> pairs` | `pair` + 一层多题 + 宿主聚合 |
| `Tournament` | `(cands: Set[M], q: Str, K) -> winner: M ⊎ unsure` | 环：`fan(K)` → choice → 胜者 ∪ unsure 组成员 → 直到 size ≤ 1；K 由候选长度定 |
| `DivideConquer` | `(doc: M, q: Str) -> Outlet` | 切块 → 每块一层 → `S.summary` 出口 → 再问 |
| `Search` | `(goal, observe: sfn, actions: sfn) -> M` | 环：观察 S → noul 找到？→ choice 选动作 → 做；已访集合在寄存器 |
| `SelectBackfill` | `(options, q, truth: sfn)` | 选型：`scale … pending`，`S.backfill` 到达后算错误率 |

`Tournament` 写法（标准库源码，也是 §4 语法的示例）：
```
circuit Tournament(in cands: Set[M], in q: Str, in ctx: M, in K: Int = 8) -> out winner: M {
  ring R(reg: Set[M] = cands) bound 8 variant host size(reg) decreasing until <= 1 {
    layer L { st = state(obj: ctx, cands: fan(reg, K=K)); c = select q among cands on st }
    c.unsure -> merge next reg                       // 平局组整组晋级
    next reg = c.pick ∪ members(c.unsure)
  }
  out winner = first(R.reg)
}
```

### 5.2 S 库（变字面函数）的注册接口
```
sfn diff_hunks(diff: M) -> Set[M] effect none = py:jc_std.diff.hunks
sfn run_tests(repo: M) -> M effect world = py:jc_std.exec.run_tests
```
规则：`effect none` 必须是纯函数（同输入同输出，编译器抽样重跑核对）；`effect world` 的观察入账本。首批 S（来自 200 任务）：`compile / extract_errors / diff_hunks / split_sentences / commit_msg / rerun / result_table / lines / window / bisect_run / summaries / columns / sample_values / header / functions / upgrade / summary / diff_config / doc_for / gen / sandbox_exec / a11y_tree / ocr / ast`。

### 5.3 题库
语义操作的字符串带校准 id（`"…"@id`），同 id 共用线与验题。题库按**物理题型**存校准（一个语义操作可能有两套校准：作为选择题与作为 K 道是非题），是非带 hi/lo；选择带置换一致率与「都不是」验题；打分带刻度指纹。

### 5.4 参照库
`scale` + `anchors` 成对存放：每档 ≥1 锚样例 [P13]；选择题的「都不是」选项模板常驻候选集。

## 6. 工具链

- **`jc check`**：4.3 的十条；另报 W-mergeable、W-K（K 超长度上限，编译器已改下沉方式）、W-nogain（层内无任何语义操作，只有 S）。
- **`jc lower`**：打印每个语义操作被下沉成什么题型、为什么（K、候选长度、偏置数据），以及融合与裂变的结果（哪些操作合成了一次调用、哪些状态被切成几块）。
- **`jc plan`（干跑）**：输出每层一行：`层 | 状态数（含裂变） | 题数（含融合） | 预估 token | 预估 $ | 预估 τ`，按 271 + 状态 + 0.88×题 与 τ≈1 s、35 次/s 计 [P5]；环按 bound 给最坏值；与 `budget` 比对。E8 材料上要求与实跑误差 ≤20%。
- **`jc run`**：按计划分层执行；四道终止（层上限、键重复、步数、钱）；每层出口与分布写轨迹。
- **`jc replay <run> --layer n`**：关网重放到第 n 层，显示每个 Call 的出口、三种题的分布（选择题 K 项分布与置换前后 argmax、打分题档位分布）、以及导致下一层状态的那些出口。
- **`jc trace`（viewer）**：电路图上叠成本与出口计数，点任一线回到产生它的 Call 与账本键。
- **诊断（七类编译错误各报什么）**：
  1. 读数接线：`q1.p 不是线；出口只有 act/ignore/unsure/pick/at/order`。
  2. 跨题比较：语法不存在，报为解析错误并提示「读数不可比较；若要比较两道题，用同一状态挂两题再按出口组合」。
  3. 打分无锚：`score 题 "…" 缺 anchors；刻度 X 在参照库无锚`。
  4. 概率字面量：`0.65 不是合法字面量；线只能来自 calib`。
  5. unsure 未接：`q3.unsure 未连接；接 sink escalate / sink drop / 后层 state / merge next reg`。
  6. 环无界：`ring R 缺 bound 或 variant`。
  7. 同层依赖：`layer L2 里的 state 引用了本层操作的出口；拆到下一层`。
  另：E-window（单对象超窗，含实测 token 与上限）、W-fission（已裂变，列出切法与新增层数）、E-peers（打分状态含 cands）、E-K（强制题型超实测上限）、E-order（做的顺序不可定）、E-domain（预算时间低于一层 p95，域外）。

## 9. 弱点与所赌的假设

**弱点（自评）**
1. **显式层与编译器调度打架**。程序员写的 `layer` 若与依赖推出的最优调度不一致，只能报 W-mergeable，改不了程序；子电路摊平后层号全变，程序上写的层号只是局部真。电路语言的「结构即成本」在组合后打折。
2. **交互任务写起来笨**。computer use / Agent 每步一屏一状态，环的每轮只有一层、一次调用，数据流的并行优势消失，程序退化成带寄存器的顺序脚本；`Search` 骨架能写，但比守卫命令写法长且不直观。
3. **下沉规则目前只有两个数据点**（E10 段落级、E9b 代码级）。`select` 在中等长度候选、K 在 4–16 之间的下沉边界是插值，不是实测；编译器的物理选择可能在这段区间选错。
4. **没有三值复合条件表达式**。「A 且非 B」要在同一状态挂两题再用宿主按出口组合，比 `if a ∧ ¬b` 啰嗦。
5. **可读性偏硬件**：对写惯脚本的人，`fan/merge/ring/sink` 有学习成本；十五条程序平均 11 行是因为 S 库替它们做了大部分事。
6. **裂变后的语义变化没有量**：ctx 超窗被切块再摘要，等于把一道题换成了「分块 + 摘要 + 再问」，一致率未测（能做域表「不可分解」一格）。

**所赌的假设（账本编号）**
- [#13 成立] 选择吸收配对在 K≤16/4 下成立——`fan` 的价值全系于此。
- [#14 成立·条件] 锦标赛须置换、长候选走 noul——`Tournament` 的 K 与路径选择依赖 E9c 再确认。
- [P5] 成本公式与 35 次/s——`jc plan` 的每一个数字来自它；并发上限随状态大小变（E10 附带发现）尚未量。
- [#9 未做] 内核四样独立性——本设计的节点集合（Call、S、ring、sink、host）比四样多一个 sink，是否可并入 S 未消融。
- [#26 未测] 串联翻转率——多层电路的整体错误率只有 1−(1−ε)^D 的纸面公式。
- [#22 部分] 生成进环是否把构造类任务真正带进能做域——E9c。
