## 1. 模块：从「替用户想掉一件事」出发，再消融

### 1.2 消融

- **选材器 → 并入标准库。** 它是「过滤(前提谓词) → 过滤(语境题) → 参照装配」三步固定程序，全用算子写得出（v2 §15 已定）。去掉它没有任何测试坏，只是标准库少一条规则。不保留。
- **谓词推导器 → 并入标准库。** 它是「生成候选题 → 在带标签样本上选/序 → 去冗余」的程序，算子是选、序、聚合，统计是确定性代码。去掉它，语言仍完整，只是用户要自己写谓词表。不保留为内核模块。
- **追溯 → 并入料库 + 账。** 来源链在 Item（about / made_by），每次调用在账里。viewer 是读这两处的工具，不是模块。
- **生成器 → 是「做」算子的一种实现**（写手），不是模块。
- **账 与 判 是否合并：不合并。** 去掉账，判照常工作，但重放失败（B3）；去掉判，账没有内容。两者被不同的测试证明必要，是两个模块。
- **检查 与 算子 是否合并：不合并。** 算子在运行期，检查在编译期；去掉检查，程序仍能跑，但 A5（概率渲染进 Jev）和跨题比较会静默通过，这两条是语言级保证，必须有一个编译期模块守。
- **规划器 与 执行器 是否合并：不合并。** 去掉规划器，执行器按定义顺序跑，正确但 E8 的平方项失控（595 对、$0.014 变成 11 万对、$2.5）；去掉执行器什么都不跑。两者被不同的量证明必要。

## 2. 每个模块的标准：测法、样本量、通过线

### 2.0 δ 噪声下的重复次数（后面各条引用）

实测噪声（E1）：noul δ p99 = 0.05，max 0.09；choice/score p99 0.10–0.15，max 0.18；
choice 的 argmax 约 3% 会换。把 p99 当 2.33σ 折算：noul σ ≈ 0.021，choice/score σ ≈ 0.06。

- **检测均值漂移 Δ**（双侧 α = 0.05，功效 0.8，两样本）：n = 2 × (1.96 + 0.84)² × σ² / Δ² = 15.7 σ² / Δ²。
  noul：Δ = 0.05 → n ≈ 3；Δ = 0.02 → n ≈ 17。choice/score：Δ = 0.05 → n ≈ 23；Δ = 0.15 → n ≈ 3。
- **检测出口翻转率上升**（基线 3%，单侧 α = 0.05，功效 0.8）：
  n = [1.645√(2p̄q̄) + 0.84√(p₀q₀ + p₁q₁)]² / (p₁ − p₀)²。
  3% → 13%：n ≈ 90（红队 B5 同一算式）；3% → 8%：n ≈ 380；3% → 23%：n ≈ 24。
- **估计一个错误率到 ±5%（95% CI）**：n = 1.96² × p(1−p) / 0.05²，p = 0.05 → n ≈ 73；
  现有 calib_min_n = 20 只能给 ±10%。
- **针尖失败**（一段决定性材料被丢）不能靠随机抽样，只能穷举（红队 B5b）。

### 2.6 检查（编译期）
必须报错的六条用例：读数渲染进状态；跨题比较概率；跨候选集比较 choice 读数；跨刻度比较 score 读数；算子缺 unsure 策略；迭代无上限。通过线：6/6 报错，0 误报（对试验台 A 和 mini_todo 的合法程序）。
保留 v0 的种类流 lint（悬空产出、无源之水，B9 降为 warn），并加一条：每个中间结果必须被某个聚合或选消费（B9 的替代保证）。

## 3. 三种题各自的校准

### 3.1 是非（沿用 v0，微调）
- 两条线 hi / lo：n ≥ 20 时在观测读数上扫描，act 区错误率 ≤ ε = 0.05，ignore 区漏放率 ≤ ε（calib.py 现有）。
- 迟滞 δ = 0.05。
- 验题闸门：≥ 3 act + ≥ 3 ignore，缝 gap = a_min − i_max ≥ 0.20（safety 0.30）。
- 停岗：n ≥ 20 且错误率 > 2ε。
- 改动一处：n < 73 时线附 ±10% 的标注，viewer 显示。

### 3.2 选择（新）
- **线₁ 最大概率下限** p_max ≥ L₁：从标注数据扫描，使 {p_max ≥ L₁} 里 argmax ≠ 标签的比例 ≤ ε。
- **线₂ 前二差距下限** p₁ − p₂ ≥ L₂：δ = 0.15 意味着两名各自可漂 0.15，差距 < 0.30 时名次可换；
  L₂ 从数据扫描，下限不低于 2δ = 0.30（p99 口径）。两条线都不过 → unsure。
- **位置置换**：验题时每题打乱 3 次，argmax 一致率 < 97% 的题不上岗；运行时选算子默认置换 r = 3 取多数，不一致 → unsure。
- **验题闸门**：每选项 ≥ 2 道（probe.py 现有）改为 ≥ 3 道，另加「都不是」选项 ≥ 3 道（候选集不穷尽时必需，06 §1.2）。
- **错误率扫描**：按 argmax 对标签算，分选项报；任一选项错误率 > 2ε 停岗。
- **可比性**：读数类型带候选集指纹，跨候选集比较是类型错。

### 3.3 打分（新）
- **档位线**：每档一条概率下限 L_k：{p_k ≥ L_k} 里标签 ≠ k 的比例 ≤ ε；相邻档概率差 < δ = 0.15 → unsure。
- **参照**：每个状态带同一组每档样例（06 §2.2），样例指纹进账本键；换样例 = 新题。
- **验题闸门**：每档 ≥ 3 道（现 ≥ 2）；score_tolerance = 0.5 档（现有）。
- **批不变性**：同一东西同参照在不同批次的档位一致率 ≥ 97%（E10 待测，n ≥ 90）。
- **错误率扫描**：按档位对标签，off-by-one 单独报（相邻档错与跨档错分开），跨档错 > 2ε 停岗。
- **可比性**：同题同刻度跨东西的期望可比可聚合；跨刻度是类型错。

### 3.4 验题数量汇总
| 题型 | 现有 | 建议 | 理由 |
|---|---|---|---|
| 是非 | 3 + 3 | 3 + 3 | 缝 0.20 > 2δ_noul = 0.10，够 |
| 选择 | 每选项 2 | 每选项 3 + 都不是 3 + 置换 3 次 | δ 0.15 大三倍，且要测位置 |
| 打分 | 每档 2 | 每档 3 | 同上 |
