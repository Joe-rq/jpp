## 1. 表达力边界

### 1.1 模型是什么

五种运算，一个宿主：

| 运算 | 签名 | 性质 |
|---|---|---|
| 判·是非 | M × Q⁺ → R_noul | 一跳、字面、校准、有噪声（E1）、窗口有界（E5/E6） |
| 判·选择 | M × K 个候选 × Q → K 上分布 | 相对判断，共模偏差在 argmax 上抵消 |
| 判·打分 | M × 刻度 × Q → 档位分布 | 有序度量，需参照锚定 |
| 生 | 上下文 → 有限候选集 | 外部预言机，覆盖范围 = 生成器的 pass@N 上限 |
| 做 | 动作 → M | 世界预言机，有副作用 |
| 宿主 | 任意确定性计算 | 算术、集合运算、渲染、有界迭代；数字不进判 |

### 1.2 精确刻画

能写出来的东西是：

> **窗口有界、深度有界的一跳判断电路，加上生成候选上的有界搜索，由确定性宿主连线。**

电路的门是一次 Jev 调用（一个 ≤ L token 的状态，多题），线是**出口渲染成的文字**
（不是概率），深度 D 是往返次数，宽度是并行调用数。搜索的节点由生成器给出，
访问由宿主按出口决定，步数有上限。

这个类比布尔电路里的有界深度电路（门是预言机门）：任何一层里的判断互相独立、
可以任意宽；跨层必须经过宿主。它比 Datalog 的一阶查询多了两样（生成候选、动作），
少了一样（不动点）。

由此可写的三类东西：
1. 材料上的**有界深度一阶查询**：一元、二元、三元字面谓词的合取/析取/量化，
   深度 = 谓词依赖链长度（矛盾 = 前提 → 配对 → 三题 → 存在，深 3）。
2. **候选空间上的有界搜索**：目标和约束对候选一跳可判即可（束、进化、分支限界、
   MCTS，见 §2）。
3. **文字状态的交互过程**：每步是一次 K 选一（computer use、Agent）。

### 1.3 写不出来的东西（各举一个）

- **需要不动点的自指规则**：「一条主张可信，当且仅当它被一条可信的主张支持」。
  Jev 非单调（E5/E6：加材料读数上飘或下落，出口可翻；E1：重跑翻转 3%），
  迭代可能振荡，只能有界近似，没有「最小模型」这种东西。
- **窗口内不可分解的整体判断**：「这本书最重要的一句是哪句」。可以做成
  逐窗打分再锦标赛，但那是局部极大的近似，语义已经换了。凡是分解会改变问题的判断，
  只能近似。
- **生成器支持集之外的解**：搜索的上限是生成器的 pass@N（研究/02 的验证器文献），
  判断再准也选不出没被生成的东西。
- **需要算术的判断**：「这本账平不平」。Jev 不做算术（官方；E7 隐式判断缺口 −0.05），
  必须由宿主算完再让 Jev 判算出来的结论文字。

### 1.4 两条附带性质

- 每个输出自带**推导树**：叶子是带校准错误率的读数，宿主可以按树估计整体错误
  （在叶子独立假设下；同一材料共用时不独立，估计偏乐观，要标注）。
- 深度 D 层、每层错误率 ε，无外层验证时整体错误上界约 1 − (1−ε)^D。
  规划器在可行时应**宁宽勿深**（§3 L6）。

## 2. 六种搜索算法的写法

标注：〔是〕noul〔选〕choice〔分〕score〔生〕生成〔做〕动作〔宿〕宿主。

### 2.1 束搜索
```
束搜索(Q, x0, 宽 b, 步 T):
  束 = {x0}
  重复 T 次:                                            # 层数 = T
    候选 = ∪_{x∈束} 生(x, "扩展一步，出 m 个")           〔生〕
    读 = 并行 对 c∈候选: 判(状态=c, {〔是〕"满足约束 C？", 〔分〕"离 Q 几档(1–5)"})   # 每候选一状态两题
    可行 = filter(候选, 出口_是 == act)                   〔宿〕 unsure 保留但排在 act 后
    束 = top_b(可行, 按 出口_分)                          〔宿〕
    若 出口_分(束[0]) == 最高档: return 束[0]
  return 束[0]，若其 出口_分 为 unsure 则整体 unsure
```
成本：每步 b·m 次调用（一状态两题），共 T·b·m 次；每次 ≈ 271+400+80 = 751 token。
b=4, m=8, T=10：320 次，240k token ≈ $0.010；每层 32 次 ≈ 1 s，共 ≈ 10 s（不含生成时间）。

### 2.2 进化搜索
```
进化(Q, 种群 N, 代 G, 参照 = 每档一个固定样例):
  P = 生(Q, "N 个互不相同的初始候选")                    〔生〕
  重复 G 代:                                             # 每代 2 层
    读 = 并行 对 x∈P: 判(状态=参照+x, {〔分〕"满足 Q 的程度", 〔是〕"违反硬约束？"})   # N 次
    P = filter(P, 出口_是 != act)                        〔宿〕
    父 = 并行 对 每 K 个一组: 判(状态=组, 〔选〕"哪一个最接近 Q")   # N/K 次，相对判断校正打分漂移
    子 = 生(父, "变异与交叉")                             〔生〕
    P = 父 ∪ 子
    若 出口_分 最高档的个体数 ≥ 阈 且 连续两代不变: 停
```
成本：每代 N + N/K 次。N=64, K=8, G=20：1,440 次；每次 ≈ 750 token → 1.08M ≈ $0.045；
每代 64 次 ≈ 2 s + 8 次 ≈ 1 s，共 ≈ 60 s。
说明：打分给绝对量（爬山方向），选择给相对量（抵消打分随批漂移），两者同时用是刻意的。

### 2.3 分支限界
```
分支限界(Q, 根, 步上限):
  最优 = ∅; 界 = 最低档; 前沿 = {根}
  当 前沿 非空 且 步数 < 上限:                            # 每轮 1 层，前沿并行
    读 = 并行 对 n∈前沿: 判(状态=n, {〔分〕"这条分支最多能到几档", 〔是〕"已是完整解？"})
    剪 = {n : 出口_分(n) ≤ 界}；unsure 不剪            〔宿〕 三值：只剪确定的
    完 = {n : 出口_是(n)==act}; 对完整解更新 最优、界    〔宿〕
    展 = 前沿 − 剪 − 完
    子 = 并行 对 n∈展: 生(n, "互斥且穷尽地展开下一步")    〔生〕 C11 的写法
    序 = 并行 对 n∈展: 判(状态=n+子(n), 〔选〕"哪个分支最有希望")   # 一次调用给访问顺序
    前沿 = 按 序 取前 w 个子                              〔宿〕 w 限宽，否则前沿爆炸
  return 最优 或 unsure
```
说明：经典分支限界要求上界可采纳（不低估）；Jev 的上界不可采纳，剪枝是概率性的。
校准线给出「上界读数低于界时真解仍在其中」的错误率，界要留一档余量。
成本：每轮 |前沿| 次（分+是同状态）+ |展| 次（选）。前沿 32、10 轮：≈ 640 次，$0.02，≈ 20 s。

### 2.4 蒙特卡洛树搜索
```
MCTS(Q, 根, 预算 B, 并行 C=32):
  重复 B/C 轮:                                           # 每轮 1 层
    并行 C 路: 
      n = 根; 路径 = []
      当 n 已展开: n = argmax_c UCB(c)（虚拟损失避免重复）; 路径 += n   〔宿〕算术
      子 = 生(n, "互斥且穷尽地展开")                      〔生〕
      读 = 判(状态=n+子, {〔选〕"哪一步最好", 〔分〕×K "子_i 离 Q 几档"})   # 一次调用：先验 + K 个价值
      先验 = 选的分布（宿主用作 UCB 的 P）; 价值 = 各子的档位期望   〔宿〕
      回传 价值 到 路径                                    〔宿〕
  return 根 的最多访问子
```
与 AlphaGo 的差别：策略和价值来自同一次校准调用，没有 rollout，没有训练；
价值是有序档位，不是标量回归。成本：每次迭代 1 次调用，≈ 271+600+9×40 ≈ 1,230 token；
B=1,000：1.23M token ≈ $0.05；32 路并行 ≈ 32 层 ≈ 32 s。

### 2.5 二十问
```
二十问(Q, 材料 M, 假设集 H, 问库 P, 深 D):
  若 M 装得进一个窗口:                                    # 深度塌缩为 1 层
    读 = 判(状态=M, P 里全部问题)                          〔是〕|P| 题一次调用
    H = 与全部读数一致的假设                              〔宿〕 按预先声明的「答案→假设」表
    return H
  否则 重复 D 次:                                          # 材料换窗口时才需要深度
    q* = 判(状态=H 摘要, 〔选〕"P 里哪个问题最能把 H 分开")    # 二阶：选问题
    窗 = 与 q* 有关的窗口（宿主索引）
    读 = 判(状态=窗, {q*} ∪ 该窗可问的其它题)              〔是〕 顺手问干净
    H = filter(H, 与读一致)；|H|==1 则 return
  return H（unsure 的假设保留）
```
说明：并行免费把二十问的「二十轮」压成一轮，只要材料在一个窗口里。
深度只在「答案决定下一个看哪段材料」时回来。成本：一窗 |P|=50 题：
271+400+2,000 ≈ 2.7k token ≈ $0.0001，1 s。多窗 D 轮：D 次调用，D s。

### 2.6 约束传播（弧一致）
```
约束传播(变量 X_1..X_n, 域 D_i, 二元约束集 C):
  重复直到 无域变化 或 轮数上限:                          # 每轮 1 层
    并行 对 c(X_i, X_j) ∈ C:
      读 = 判(状态=c 的文字 + 值对列表, 〔是〕"值对 (a,b) 满足 c？" × |D_i|·|D_j| 题)
      对 a∈D_i: 若 所有 b 的出口都是 ignore: 删 a         〔宿〕 只删确定的，unsure 不删
      对 b 对称
  若 某 D_i 为空: 不可满足
  若 全部单点: 解
  否则: v = 判(状态=剩余域, 〔选〕"先定哪个变量")；对 v 的每个值 递归（有界）
```
说明：域只减不增，且已问过的值对由账本缓存不重问，所以这个循环**单调收敛**，
是六个算法里唯一天然终止的。成本：每约束 1 次调用，|D|=5：25 题 ≈ 1.7k token；
20 个约束 × 3 轮 = 60 次 ≈ $0.004，3 s。

## 3. 成本与深度的定律

记 N 材料数、K 一状态里的候选/配对数、w 一状态里能装的材料数（受窗口 L 限制）、
σ 一元谓词的选择率（幸存比例）、C 并发（≥32）、τ 每层 p95（≈1 s）。

| 形状 | 调用次数 | 说明 |
|---|---|---|
| 一元是非/打分 | N / w | 一状态装 w 个材料各问一题；w 受 L 与「带主张互扰」限制 |
| 选择 | N / K 每轮，锦标赛 ≈ N/(K−1) 共 log_K N 层 | 相对判断 |
| 配对（二元） | N_s² / 2 | N_s = 一元筛后的幸存数 |
| 选择吸收配对 | N_s · N_s / K | 每状态 a + K 个对手，问 K 题或 1 道选择 |
| 生成上的搜索 | Σ_t 候选_t × 1 | 约束与目标同状态，一候选一次 |

**L1 调用定律。** 钱和时间都按调用次数走（E4 v2：时间与题数无关；E8：271 固定开销
在小片段占 77%，两题合一省 45%）。同一状态能问的全部一次问完，永不拆开。

**L2 窗口定律。** 状态 ≤ L（带主张材料约 500 token，中性填充可到 8,000，E5/E6）。
w = L / 材料大小。材料带主张时 w 取小，宁可多分层。

**L3 层内全问、层间按选择率排。** 同一层的谓词互不依赖，全部挤进同一次调用，
顺序无意义。只有**材料或问题依赖上一层出口**时才开新层；层间顺序按
rank = (σ − 1) / 代价 升序（Predicate Migration），一元代价 ≈ 相等时即按 σ 升序。

**L4 平方定律。** 二元代价 ∝ N_s²/K。多加一道选择率 σ 的一元筛，二元代价乘 σ²，
一元只加 N_s/w。只要 σ < 1 且 N_s > w/(K(1−σ²)) 就值得加。规划器第一职责：压 N_s。
一元筛选率不够（σ 接近 1）而二元选择率极低时，顺序反过来（PLOP 已证先过滤不总最优）。

**L5 深度定律。** 时间 ≈ Σ_层 max(τ, 调用数_层 / 35)。一层 ≤ 32 次调用 ≈ 1 s；
一层 1,000 次 ≈ 30 s。

**「几秒几千次判断」的成立边界。** 判断数 = 调用数 × 每次题数。
- 每次挂 ≥ 20 题、层数 ≤ 5、每层调用 ≤ 64：几千次判断 ≈ 5–10 s。**成立。**
- 每次 1 题（每候选各自一状态、一题）：1,000 次判断 = 1,000 次调用 ≈ 30 s。**不成立。**
- 边界公式：T ≈ D × max(1, N_调用/35)；要 T ≤ 5 s 且 判断数 ≥ 1,000，
  需 D ≤ 5 且 每次题数 ≥ 1,000 / (5 × 35) ≈ 6，实际留余量取 ≥ 20。
- 配对形状下：N_s = 74 段筛到 35，595 对，2 层，20 s（E8 实测，每对一状态三题）。
  用选择吸收（K=8）：35 × 5 = 175 次调用，2 层，≈ 6 s。N_s = 200 时：
  配对 20,000 次 ≈ 10 分钟；吸收后 5,000 次 ≈ 2.5 分钟；再加一道 σ=0.5 的一元筛：
  N_s=100，1,250 次 ≈ 40 s。

**L6 宁宽勿深。** 深度既花时间（每层 τ）又累积错误（1−(1−ε)^D）；两条路可行时选层少的。

**L7 生成定律。** 搜索成本 = Σ_t 候选数_t。约束（是非）和目标（打分）挂在同一状态，
一候选一次调用。锦标赛 ≈ N/(K−1) 次、log_K N 层。

## 4. 原创与借用

### 4.1 借用（标明出处）
- 半朴素求值的 full/delta/new 与依赖图取 SCC 分层：Soufflé/DDlog/Ascent（研究 §2.1）。
- rank = (σ−1)/代价：Predicate Migration 1993（研究 §3.3）。
- 层边界重规划，不逐元组路由：Spark AQE 对 Eddies 的取舍（研究 §3.2）。
- 强 Kleene 三值与 Mostowski 量词 max/min：研究 §5。
- 函数缓存 ↔ 账本按键复用：Predicate Migration / PLOP。
- 离线目录估选择率：SemStats（研究 §3.3）。
- 相关减冗余的形状：mRMR（研究 §4.1）。
- 生成多选一的范式：Cobbe 2021 验证器、AlphaCode（研究/02）；策略+价值+树搜索：AlphaGo。
- 束、进化、分支限界、弧一致：经典算法。

### 4.2 原创（每条追溯到一条已测事实）

| # | 原创点 | 来自哪条事实 | 先行系统为何没有 |
|---|---|---|---|
| O1 | **以调用次数而非判断次数为成本轴**：同状态全部题一次问完是第一优化目标 | E4 v2 时间与题数无关，每题 37.7 token；E8 271 固定开销、合并省 45% | 它们的成本轴是调用次数 = 判断次数，优化全在减少调用 |
| O2 | **二十问塌缩成一轮**：材料装进窗口时，问库全问，事后选 | 同 O1 | 它们一题一调用，二十问就是二十轮 |
| O3 | **窗口常数 L 作为电路深度的来源**：深度不是设计出来的，是材料量 / L 与依赖链长出来的 | E5/E6：带主张 500 token 起带偏，中性到 8,000 | LOTUS 用「一行一调用」绕开，没有量出常数，也就没法批到常数 |
| O4 | **选择吸收配对 N²→N²/K 且带相对校准** | E8 配对 595 对 $0.014 + E4 多题成本 | 语义 join 全是逐对或 embedding 代理 |
| O5 | **有界迭代取代不动点，账本只增** | E1 δ：noul p99 0.05、choice/score 0.12–0.18、argmax 翻 3%；E5/E6 非单调 | Datalog 假设单调；Scallop 半环要吸收律 |
| O6 | **数字不进判，只有出口渲染**（读数无渲染函数） | E7 隐式双重判断缺口 −0.05；官方不做算术 | 它们把 logprob 当分数继续算 |
| O7 | **概率性剪枝**：分支限界的界用校准线的错误率定余量，unsure 不剪 | 校准闸门与错误率扫描（v0 §5.4，S 系列验收） | 它们没有校准概率，剪枝要么可采纳要么启发式 |
| O8 | **打分做适应度不需训练，参照是一等材料**，批不变性可测 | E3 批处理无偏（账本键排除批次）；choice/score δ 0.15 迟滞 | 验证器路线要训练 reward model |
| O9 | **选材是字面前提判断，不是元判断** | E8：元题 72% 读数 < 0.2，前提题双峰 | 它们让 LLM 自己判「相关性」，正是元题 |
| O10 | **选问题用选择题**（二阶：哪个问题最能分开样本），条件于目标 | E4 题便宜；红队 A4 与 mRMR 独立得出需目标信号 | 它们的问题是人写死的 |
