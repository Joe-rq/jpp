# 首发与后续运营

## 仓库定位

名称：J++。仓库短名：jpp。版本：0.1.0a1。定位：实验性编程语言，当前以 Python 嵌入式语言交付。

GitHub 简介：An experimental language for composable semantic computation. Questions and methods as values.

建议 topics：programming-language, experimental, semantic-computing, composition, python, jev。

## 首发动作

1. 仓库公开并通过 CI 后，把运行结果填入首个 prerelease。
2. 用离线示例录制 30–60 秒终端演示：安装、运行、展示结果、指向源码。
3. 使用本目录中英文文案，附仓库链接和演示；先向真正会尝试的人介绍。
4. 首周重点处理安装失败、接口理解和新增方法三个主题。

## 发布后衡量什么

优先统计成功运行的人、外部可复现问题、外部贡献的新方法及其复用程度。Star 是传播信号，不能代替这些使用结果。

每周发布一则具体进展：新增什么、运行什么程序能看到、仍在解决什么。没有新结果时不强行制造更新。

## 常见问题

**现在是完整独立语言吗？** 当前是嵌入式语言与运行内核；独立语法仍在设计。

**为什么不用 Python 直接写？** 当前正是用 Python 实现。我们在提炼问题、效应和方法组合的通用结构，让算法之间更容易复用。

**和 JEV 是什么关系？** JEV 是判断后端的起点。J++ 是独立项目，后端适配可继续发展。

**示例证明模型能十次解决任何问题吗？** 没有。示例使用合成二元回答展示自适应提问机制；真实任务需要单独评价问题质量和判断误差。

**名字和微软 J++ 重名吗？** 显示名称是 J++，项目明确说明与 Visual J++ 无关；链接和包名使用 jpp / jpp-language 区分。
