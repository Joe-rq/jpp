# Introducing J++: compose questions, methods, and their compositions

J++ is an experimental programming-language project exploring semantic judgment as a programmable operation. We want questions and solving methods to be reusable values, so a complex method can become a building block in another method.

The first alpha contains a Python embedded language, a runtime, and a composition library. Its offline demo combines adaptive inquiry and counterexample feedback. No API key is required: model observations are synthetic, while the algorithms and finite-domain checks actually execute.

We are opening the project while its design is still evolving. We would love examples of new methods built from the existing components, especially ones that reveal what the language is missing.
