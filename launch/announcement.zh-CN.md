# 我们开始做一门新的语言：J++

如果问题可以像数字一样传递，求解方法可以像函数一样组合，而组合后的方法还能继续参与组合，会发生什么？

这是我们做 J++ 的起点。我们希望把 JEV 风格的语义判断与精确算法、生成、检查和反馈放进一套可复用的编程结构里，让开发者能构造我们没有预先想到的方法。

今天放出来的是早期实验版本：Python 嵌入式语言、运行内核和组合库。下载后可以离线运行两个例子：不断选择下一道问题，从 1,000 个候选里定位目标；用检查产生的反例改进候选，构造满足指定输入要求的表达式。两个例子使用合成观察，体验不需要 API Key。

我们选择在语言尚未定型时开放它，因为我们最想知道的是：别人会用这些基本单元构造出什么？如果你熟悉算法、语言设计，或者只是想写一种新的求解方法，欢迎带着能运行的小程序来参与。
