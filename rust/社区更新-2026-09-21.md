# J++ 最近两小时的进展：现在可以直接写源码运行了

我们一直想做的，是让“问题”和“解决问题的方法”都能成为编程的基本材料：方法可以传给另一个方法，组合出来的新方法，还能继续参与组合。

最近两小时，我们把这件事推进到了一个具体节点：**现在可以直接写 `.jpp` 文件，由原生 Rust 程序检查并运行。** 安装后的程序不需要 Python。之前的实现和实验继续保留。

已经跑通的例子里，一个程序会根据上一题的答案，自己构造下一道问题，十次判断在 1,000 个候选中找到目标。另一个程序在部分候选还“不确定”时，先交出成本 9 的可用方案；随后换一种提问策略，得到成本 2 的方案，之前做过的检查不需要重做。这些算法和继续求解的方法写在 J++ 源码里。这一组使用固定答案，验证的是语言怎样执行和组合。

应用实验也往前走了一步：一个两人的合作提议，可以重新成为输入，继续寻找第三位成员。我们用同一套发现组件运行不同任务，并公开了录制与可交互演示。这个实验使用 216 份合成人物资料与真实 JEV 调用，目前沿用 Python 参考实现，尚未迁移到新的 Rust 源码路径。

原生整包的 41 项测试和 GitHub 检查已经通过。自动审查也指出了缓存标识、成本记录与算术边界等需要修正的问题；下一步先处理这些正确性问题，再把常用源码方法整理成标准库，让更多人能方便地构造自己的程序。

这还是一门正在生长的实验语言。我们最期待的是：有人用这些基本单元，组合出我们自己没有想到的方法。
