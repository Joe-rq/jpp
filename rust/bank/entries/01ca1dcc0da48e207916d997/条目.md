## 1.1 题式

- **题型**：`test`（两侧线）。
- **模板**：`这项操作一旦执行，是否就很难或无法完全撤销？`，题式记录 `{calib: "attr-hard-to-undo"}`，将定义在 `lib/bank/hard_to_undo.jpp`（草案：`地基/题库/第二批/草案/C01-难撤销.jpp`，读数用的程序 `read.jpp` 里的题式与它逐字一致）。没有填法槽，材料是一项操作的一两句文字描述，用 `state(mat(描述))` 判。
- **极性**：固定为「是 = 难撤销」。来源里有一处问反向（「能否完全撤销」），按极性翻转归并（主控 2026-09-29 认可）。
- **题的五件**：主体 = 一项操作的描述；谓词 = 该操作一旦执行就很难或无法完全撤销；划分 = 是 / 否；请求 = 概率；前提 = 无声明。
- **题类**：检查器基础类与精化类都是属性（推断）；记录 `kind: attr`。
- **标注口径**（B119，不进模板）：
  1. 描述里明说一步就能恢复的路径（回收站、版本历史、一键回滚、有可用备份且恢复是例行操作）：否。
  2. 描述没提恢复路径，而动作会永久删除、覆盖、对外发出、付款或转出：是。
  3. 已被他人接收或看到的对外动作（发出的邮件、已公开发布的内容、已付出的钱）：是，即使没有东西被销毁。
  4. 只读，或新建可随时删除的东西，或只改本人随时能改回的设置：否。
  5. 能恢复，但要花明显代价（重新录入几天的数据、联系外部机构、付费恢复）：是。
  6. 描述缺关键信息、无法判断：ambiguous。

6. **理解偏差与更正**：第一轮在材料生成者仍在改写 `materials.json` 时就出包、跑真机、标注，作废重做（见 `作废-未定稿材料/说明.md`）。预注册对 Sonnet 与设计意图一致的预测是 ≥ 68/80，实测 80/80，边界条设计得偏清楚，对口径 5 的检验力有限；线窄的原因同此。难例补充（裁定三十一）没有让线变宽，见 1.3。
