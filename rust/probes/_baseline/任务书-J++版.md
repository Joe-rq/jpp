# 任务书 · 用 J++ 写的版本（非设计者版）

2026-09-24 加（步 31-1；`地基/附注/2026-09-24-仪表读数1裁定.md` §三 B79：J++ 侧另请不参与设计的人按同一任务书写一份）。
功能要求与 Python 版完全相同：读 `任务书-通用.md` 与项目任务书。本页只写 J++ 版与 Python 版不同的地方。

## 你能看的

- `probes/_baseline/任务书-通用.md`、`probes/<项目>/baseline/任务书.md`（T0 版只读到各自的「T1」标题之前；T1 版全文）。
- `probes/<项目>/baseline/materials.json`（T0）或 `probes/<项目>/baseline/t1/materials.json` 与 `labels.jsonl`（T1）。
- `地基/rust-jpp/GUIDE.md`（J++ 一页纸入门）与它说要 `import` 的 `地基/rust-jpp/lib/outcome.jpp`。
- `target/debug/jpp --help` 的输出。

不要打开：其他 `.jpp` 文件（`examples/`、`probes/` 下别人的程序）、`crates/`、`INTERFACE.md`、`FRONTEND.md`、`地基/` 下的设计与评估文档、
`scripts/` 下的文件（只运行验收命令）、任何 `expected*.json` 与 `fixture*.json`（验收命令会用它们，你不要读）。

## 文件与运行

- 文件：`probes/<项目>/jpp-nd/<项目名>_t0.jpp`（T0）或 `probes/<项目>/jpp-nd/<项目名>_t1.jpp`（T1）。运行目录是 `probes/<项目>/jpp-nd/`。
- 材料：程序自己读 `materials.json`（`jpp --help` 列出了已登记的动作）。
- 题面、材料形状、阈值键名照项目任务书写；固定观察按「材料 + 题面 + 题型 + 阈值键」取读数，写错一个字就取不到（会报「固定观察未命中」）。
- 程序的返回值就是输出：一个记录，字段与任务书「输出」一节相同。多出任务书没要求的字段不影响验收（J++ 要求随返回值交出的未决责任等可以放在多出的字段里）。
- 验收：在 `地基/rust-jpp` 下运行 `python3 scripts/measure_expr.py --check <项目>`（T0）或 `… --tier t1`（T1），看关于你那个 `.jpp` 文件的行。

## T0：阈值

T0 的阈值在固定观察里已经给了（验收用的夹具里带校准记录）。程序按阈值键名写题，不要在程序里写阈值数字。

## T1：四项职责在 J++ 里怎么落

| 任务书 T1 | J++ 版的要求 |
|---|---|
| (a) 账本与重放 | `jpp run` 的 `--ledger-out`、`--replay` 已经做到；程序不用写。验收用这两个参数跑你的程序。 |
| (b) 预算停机 | 程序头的 `budget {calls: …}` 就是预算。验收会把 `calls:` 后面的数字换成任务书给的 N 再跑，所以这个字段写一个数字字面量。返回值要有任务书规定的 `unobserved` 字段，其余字段按任务书「问不到的项不算任何回答」计算。 |
| (c) 合批与轮数 | 按任务书的层与上限：调用数取运行报告的调用数，轮数取账本里的层数。 |
| (d) 认证线 | 材料里没有阈值。线由 `jpp calib-import <labels.jsonl> --calib-out <目录>` 从标注算出，运行时 `--calib <目录>` 交给程序；验收替你跑这两步。程序里不写阈值数字，题照阈值键名写。`--print-lines` 与「待真值」输出由 `calib-import` 承担，程序不用写。 |

## 纪律

不运行 git，不改你那个 `.jpp` 以外的任何文件。按你在真实项目里写这个功能的方式写；一行不超过 100 列（中文按 2 列）。
开始前 `date '+%F %T'` 记开始时间，验收第一次通过后再记结束时间。回报两个时间、验收输出、验收跑了几次、文件路径、卡在哪里（若有）。
