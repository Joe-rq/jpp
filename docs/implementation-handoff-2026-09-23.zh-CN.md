## 首包：共同构造与两份完整源码程序

### 要补出的能力

| 能力 | 行为要求 | 起点与自由度 |
|---|---|---|
| 集合判断与分流 | 有限输入集合按判断分为接受、忽略、未决；保留原元素、对应观察和未决去向 | 复用 `observe_test`、`cut`、`handle`；普通布尔 `filter` 不改成另一种含义 |
| 集合汇总 | 已完成观察范围内给出存在、全称、计数范围等结果；结果可作为后续方法输入 | 使用精确计算；例如完整处理的 5 项中 2 接受、1 忽略、2 未决，计数范围为 [2,4]，不是概率区间 |
| 关系构造 | 两组输入或调用者提供的候选对，通过传入的方法形成关系记录；记录可进入上述分流与汇总 | 先用小型有界集合；关系判断方法和候选枚举方式可替换，不把整个匹配算法塞进内置命令 |
| 未决续接 | 已有部分可用；调用者换方法或补材料后推进剩余部分，结果再交给下游 | 提炼 `partial.jpp` 的 `packet/advance` 思路；具体数据结构由实现决定，不预设新关键字 |

这是能力清单，不要求恰好四个函数，也不要求新增四种核心原语。先把不同程序写通，再提炼稳定的共同结构。模型接受的判断仍是模型判断，精确集合运算不会把它变成客观真值。

### 两个程序应让人看到什么

**程序 A：找材料并形成可继续回答的问题。** 输入一批短材料和调用者的问题。输出找到的材料、当前判断范围及需要补信息的项；将选出的材料交给第二个问题继续计算。通过传入的方法或目标参数，分别表达“任意一个”“输入顺序中的第一个”“全部”。首包可采用小型完整集合求值，不强制同时实现所有提前停止优化。顺序靠前的项未决时，不能把后面一个已接受项无条件称为“第一个”。

**程序 B：发现组合，再让组合参与发现。** 输入两组成员材料，先得到候选关系，经语义判断及普通预算/技能约束组成候选组合；保留成员和依据，再把一个组合当作新输入，与第三个成员或另一组合继续计算。第二轮使用相同的关系/分流构造，不为它新增“团队发现”内置。不得从两两关系直接推定整体组合一定成立，需要明确第二轮究竟检查了什么。

两个程序都以原生 `.jpp` 为主体，可使用小型合成材料和固定观察验证执行。固定答案不能只写进最终展示结果，必须由程序实际经过判断接口和组合过程产生输出。用户能从输出看见“输入是什么、形成了什么、什么还未决、换方法后变化在哪里”。此包的效果是共同构造已经可用；真实模型的效果在第二包单独交付。

### 首包完成条件

- 两份程序导入共同源码库。新增第二份程序不需要专属 Rust 求解器；组合产物确实重新进入同一类方法。
- 换一个观察/处理方法会产生预期行为变化；至少一个例子返回可调用的方法或续接方法，证明不是只共享几行格式化代码。
- 对完整输入，接受、忽略、未决不漏项且互斥；保留重复输入的原有含义。预算提前停止时说明尚未观察范围，不能把它混成否定或已完成观察。
- 针对上述语义写必要行为测试，覆盖一个未决、一个顺序差异和一次续接；重放不新增调用。复用已有测试设施，不写镜像实现的数量型测试。
- 给出可运行命令与简短输出说明，记录共同库、两份源码、宿主配套分别有多少代码。若有现成可比实现，说明少写了哪一段协调逻辑；没有就如实说明，不声称已经达到数量级提升。
- 同步必要代码、测试与中英说明到公开分支/PR。与 PR #25 重叠的改动先核对差异，只搬缺失提交或文件，不整树覆盖公开仓库。

参考文件：`crates/jpp-cli/tests/library_lifecycle.rs`、`source_execution.rs`；核心续接行为可参考 `crates/jpp-core/tests/partial.rs`。遇到阻塞构造的具体核心缺陷，用最小源码复现并做必要修复。仅出现抽象上的不满意，不启动全系统重设计。

## 第二包：同一源码接上真实 JEV

复用 `crates/jpp-core/src/effects.rs` 中的 `JevClient` 与现有 transport/client 接口。当前 `crates/jpp-cli/src/run_io.rs` 在有无 `--fixtures` 时都选择 `FixedClient`，`options.rs` 也没有真实后端入口：这里是明确的接线位置，不是重新写模型 SDK 的任务。

交付要求：调用者用明确选项选择真实后端，凭据使用现有环境配置且不进代码或报告；固定观察与重放路径保留。第一包的同一份算法源码可在两种后端下运行，报告区分真实调用、录制和重放。用现有测试替身覆盖接线与失败；已有授权和可用环境允许时，再执行有界真实调用并留下实际结果。

现有 `--calib` / `--calib-out` 只完成资产读写的一部分。普通运行产生的无标签观察不能自行变成真值；复用现有宿主认证机制，提供被选程序实际需要的标注/独立检查输入路径和清楚的使用说明，不在首包重做一整套校准平台。真实调用受阻时完成可做的接线、测试和文档，准确报出缺少的配置或授权，不拿替身冒充 live 成果。

## 第三包：完整使用路径与发布
