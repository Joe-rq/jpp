# 陌生发现：怎样比较 J++ 与通爻旧方法

我们要找到的是：一个模糊意图遇见陌生人的上下文后，能够发现哪些值得继续了解的关联。验证这个能力，需要同时看已知关联是否被找回，以及新找到的关联是否有具体依据。

## 相同样本上的本轮重跑

216 个合成主体、20 条旧意图，所有方法均获得同一份档案、意图与补充上下文。当前主体池包含 89 个已知正例关系，分布在 18 条意图中；另两条没有池内正例，不计算其召回率。未知关系不作为负例。

| 方法 | 前十找回已知关系 | 已知正例 Recall@10 |
|---|---:|---:|
| MiniLM 整段编码 + cosine | 32 / 89 | 36.0% |
| MiniLM 分字段编码 + 平均归一化 + cosine | 44 / 89 | 49.4% |
| BM25 词面检索 | 43 / 89 | 48.3% |
| 初版 JEV 读数层级 + alias 排序 | 33 / 89 | 37.1% |
| J++：JEV 相关性分组 + BM25 组内排序 | 56 / 89 | 62.9% |

相对于分字段 MiniLM，J++ 在 7 条意图上找回更多、10 条持平、3 条更少。“懂密码学的人”“项目需要安全审计”“部署大流量后端”是这次退步的三条，均保留。相对于 BM25 是 7 条更多、13 条持平。不能只选胜出的例子展示。

MiniLM 使用 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` 的本机完整缓存，模型 revision、依赖版本、全部 216 人的每条查询排名和分数见 [embedding-report.json](demos/towow/population/embedding-report.json)。这是重跑历史方法家族：当前档案已按 alias 合并，分字段版本覆盖每个当前字段，运行后端为 PyTorch CPU，因而不冒充原 447 档案实验的精确复现。预先指定整段与分字段两种变体，两种结果均保留。

J++ 的分组排序是在查看初版开发结果后修改的，不是盲测。没有重新调用模型；真实回答、初版结果和改进结果分别保留在录制、`live-report.json`、`analysis.json` 中。当前材料都是旧开发数据，已知正例名单也不完整，这些数字不能称为总体准确率。

## 时间与费用分别算哪些步骤

| 本轮步骤 | 耗时 | API 费用 |
|---|---:|---:|
| MiniLM 整段档案建索引，一次 216 人 | 9.047 秒 | 0 |
| MiniLM 分字段档案建索引，一次 216 人 | 43.805 秒 | 0 |
| MiniLM 编码全部 20 个查询 | 0.477 秒 | 0 |
| 向量矩阵检索全部 20 个查询 | < 0.001 秒 | 0 |
| JEV 首次完整计算 4,320 个关系判断 | 29.823 秒 | 约 $0.039198 |
| 相同输入重跑 J++ | 复用 4,320 个判断 | 新增 0 |

模型加载时间另存，不混入索引或查询。向量索引在人物资料不变时可以跨查询复用；J++ 目前复用的是相同材料和问题的判断。新意图不等于相同问题，不能宣称新意图也无需调用。因此这次结果支持进一步研究质量与开销的组合，不支持“JEV 比向量搜索更快更便宜”的结论。

## 旧实验已经做了什么

旧 `tests/field_poc` 的 Phase 0–2 使用 447 份四场景合成档案。后来的 EXP-005/006/007 使用 BGE-M3 + SimHash，单查询找回 52 / 95 个旧名单正例；多视角 EXP-007 找回 34 / 95。候选池、去重规则和本轮不同，不把它们和上述百分比横排评胜负。

EXP-008 还使用 Claude Sonnet 对旧检索结果逐人评三个维度：直接相关、互补价值、意外发现，每项 1–5 分。其单查询候选总价值平均 109.1，多视角 103.85；配对差异区间跨零。评分仅覆盖旧检索器的 Top-10 并集，不覆盖 J++ 新发现的人，不能把这批旧评分当作新方法的完整裁判。旧文件没有保存模型裁判的 token 和费用，不能据印象声称旧方法更贵。

旧的 `expected_hits` 命中率与 `min_hits` 通过率不是准确率；所有 `anti_hits` 均为空。评估“陌生发现”，下一步应对各方法候选并集做匿名、同标准的独立评阅，并保留“依据不足”，分别报告直接关联、互补关联和新发现价值。若要完整召回率，需要对池中全部关系建立标签；只评候选并集只能比较这个并集上的质量。

## 复现

J++ 与 BM25：`python -m jpp.towow_population --out run-data/population`，默认离线读取真实录制。

MiniLM：单独环境安装 `sentence-transformers`，准备模型权重后运行 `HF_HUB_OFFLINE=1 python scripts/benchmark_towow_embeddings.py --model /path/to/model-snapshot`。脚本不调用远程 API，不将样本发送出去。模型依赖不加入 J++ 核心安装要求。
