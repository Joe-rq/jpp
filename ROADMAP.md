# Roadmap / 路线图

Milestones are outcome-based, without speculative release dates.

| Milestone | Acceptance / 完成标准 |
|---|---|
| Reproducible alpha | A new user installs the package, runs the offline demo and tests using the README |
| Broader composition | Contributors build three substantially different new methods without modifying the core |
| Live judgment example | One real-backend example includes its data, calibration procedure, quality measurements and cost |
| Language specification | Inputs, outputs, effects, uncertainty and composition laws have executable examples and counterexamples |
| Independent syntax | A small parser lowers to the same runtime and agrees with the embedded implementation on shared programs |
| Backend portability | A second backend implements the same observation contract with measured behavior |

Current development starts with reusable semantics and executable programs. New primitives should replace demonstrated duplication or enable a concrete method, and should be compared with an implementation that omits them.
